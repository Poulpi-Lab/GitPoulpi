# はじめに

このページでは、インストールしたばかりの状態から最初の commit までを説明します。
[インターフェースツアー](interface-tour.md)ではウィンドウのすべての領域に名前を付けています。
[設定](settings.md)にはすべてのオプションが載っています。

## 1. インストールして起動する

[インストール](installation.md)に従ってください。その後、Git リポジトリ内でターミナルを開いて実行します。

```
gitpoulpi-tui
```

サブコマンドなしの `gitpoulpi` も同じ動作をします。GitPoulpi は、現在のフォルダーを含むリポジトリを開きます。
リポジトリの外では**ホーム**タブが開き、そこでリポジトリの参照、クローン、初期化ができます
（[手順 7](#7-リポジトリを開くクローン初期化) を参照）。

アイコンには Nerd Font か、絵文字を含むフォントが必要です。四角が表示される場合は、
[トラブルシューティング](troubleshooting.md)を参照してください。

![メインウィンドウ：左に Refs サイドバー、中央にログのグラフ、右に作業中の変更と commit フォーム](../images/hero.png)

## 2. 残りのすべてを学ぶための 3 つのキー

| キー | 開くもの |
|---|---|
| `?` | **ヘルプ**：すべてのキーとマウス操作。入力で絞り込めます。`Ctrl+D` でこのドキュメントをブラウザーで開きます。 |
| `Ctrl+P` | **コマンドパレット**：入力してコマンドを探し、`Enter` で実行します。各行にそのショートカットが表示されます。 |
| `Ctrl+,` | **設定**。タイトルバーの × の左にある歯車でも開けます。 |

すべての操作はキーボードでもマウスでもできます。パレットからはすべてのコマンドに届きます。
[キーバインド](keybindings.md)と[マウスとジェスチャー](mouse-and-gestures.md)を参照してください。

![stage という語で絞り込んだコマンドパレット。ステージのコマンドがショートカット付きで並んでいる](../images/palette.png)

## 3. 履歴を見る

ウィンドウの中央が**ログ**です。commit 1 つにつき 1 行で、新しいものが上に並びます。
ブランチと tag は色付きのピル、グラフ、メッセージ、作者、日付、短いハッシュとして表示されます。

- commit をクリックします。右側にその詳細と変更されたファイルが表示されます。
- 変更されたファイルをクリックします。中央にその diff が開きます。`Esc` で閉じます。
- `j` / `k` または矢印キーで選択を移動します。`f` で commit を検索します。
- commit を右クリックすると、そのメニューが表示されます。

![merge commit を選択したログ：右側にそのメッセージ、作者、追加する 2 つのファイル](../images/log-graph.png)

## 4. 変更してステージする

エディターでファイルを編集します。**ログの最上行**に作業中の変更が表示されるようになります。
変更されたファイル数を示す破線の行です。それをクリックします。右ペインに**未ステージのファイル**と**ステージ済みのファイル**が表示されます。

- ファイルにカーソルを重ねて、その**ファイルをステージ**ボタンをクリックします。または**すべてステージ**をクリックします。
- ファイル名をクリックすると、その diff が開きます。そこでは 1 つの**ハンク**（**ハンクをステージ**）
  または 1 つの**行**をステージできます。

[ステージと commit](staging-and-committing.md)を参照してください。

![変更したファイルの diff。各ハンクの上にハンクをステージとハンクを破棄のボタンがある](../images/diff.png)

## 5. commit する

右下の commit フォームに概要を入力します。説明は任意です。その後、緑の
**N ファイルの変更をcommit** ボタンをクリックするか、`Ctrl+Enter`（どこからでも使える `Ctrl+G Enter` も可）を押します。
**直前のcommitを修正（Amend）** にチェックを入れると、変更を最後の commit に追加します。

[AI](ai.md) をオンにしている場合、概要の横の `✦` ボタンが、ステージした変更からメッセージを書いてくれます。
GitPoulpi は、**N ファイルの変更をcommit** をクリックするまで commit しません。

## 6. 作業を共有する

ツールバーには **Pull** と **Push** のボタンがあり、それぞれに `▾` の一覧があります。キーボードからは
`Ctrl+G` を押してから文字を押します。`Ctrl+G p` で pull、
`Ctrl+G Shift+P` で push します。`Ctrl+G` の後は、ステータスバーに文字の一覧が表示されます。

GitPoulpi は、お使いの `git` がすでに使っている認証（認証情報ヘルパー、ssh-agent）を使います。
独自のアカウントは不要です。pull request を見たり作成したりするには、ホスティングアカウントを
一度接続します。[ホスティングと Issue トラッカー](hosting-integration.md)を参照してください。

## 7. リポジトリを開く、クローン、初期化

タブ行の左端の家のアイコンをクリックするか、`Ctrl+O` を押します。**ホーム**タブに、開いている、
お気に入り、最近のリポジトリが一覧され、**参照**、**クローン**、**初期化**のボタンがあります。
各リポジトリはそれぞれのタブで開きます。`Ctrl+W` で現在のタブを閉じます。

![開いている、最近のリポジトリを一覧し、参照、クローン、初期化のボタンがあるホームタブ](../images/home.png)

**クローン**は URL とフォルダーを尋ねるか、接続したアカウント（GitHub、GitLab、Gitea、Forgejo、Azure DevOps、Bitbucket、Gerrit）からリポジトリを選ばせます（[接続したアカウントからクローンする](hosting-integration.md#接続したアカウントからクローンする)を参照）。**初期化**はフォルダーを新しいリポジトリにします。
この 3 つのダイアログ（と、そこから開くフォルダーピッカー）では、`Ctrl+N` で各フィールドとボタンにバッジが表示されます。その文字を押すと、フィールドにカーソルが移るか、ボタンが押されます。

| ![クローンのダイアログ：クローン先、URL、フォルダー名、キャンセルとクローンのボタン](../images/clone.png) | ![リポジトリを初期化のダイアログ：フォルダー、名前、初期ブランチ](../images/init.png) |
|---|---|

### スパースチェックアウト

大きなリポジトリを丸ごとディスクに置く必要はありません。クローンのダイアログで **スパースチェックアウト（一部のディレクトリのみ）** にチェックを入れ、必要なディレクトリをスペースまたはカンマ区切りで入力します（`src docs/guide`）。チェックアウトされるのはそれらのディレクトリとリポジトリのルート直下のファイルだけです。履歴全体はそれでもダウンロードされるので、ログ、blame、ブランチはいつもどおり使えます。チェックを入れている間は、ディレクトリを 1 つ以上入力する必要があります。

![2 つのディレクトリを入力したスパースチェックアウトのダイアログと、キャンセル、オフにする、適用のボタン](../images/sparse-checkout.png)

どのリポジトリでも後から切り替えられます。コマンドパレット（`Ctrl+P`）を開いて **リポジトリ: スパースチェックアウト...** を実行するか、リポジトリのタブのメニューにある **スパースチェックアウト...** を使います。ダイアログには、現在チェックアウトされているディレクトリが 1 つの欄に一覧されます。そこで名前を追加または削除して **適用**（`Enter`）を押すか、**オフにする（フルチェックアウト）** で、すべてのファイルを元に戻します。作業ツリーがスパースの間、ステータスバーに小さな `スパース` のバッジが表示されます。同じ操作は *設定 > スパースチェックアウト* のページにもあります（1 行に 1 パスの一覧と、**スパースチェックアウトを開始**、**スパースチェックアウトを終了**、**スパースチェックアウトを更新**のボタン）。

補足：

- git の cone モード（パターンではなくディレクトリ）です。`*`、`..`、絶対パスは拒否されます。
- 対象の変更は「元に戻す」には記録されません。失われるものはなく、**オフにする** ですべてのファイルが戻ります。commit していない変更があるディレクトリを外そうとすると、git が拒否することがあります（エラーはステータスバーに表示されます）。先に commit または stash してください。
- スクリプトやエージェントからも同じことができます：`gitpoulpi clone <url> --sparse src docs` と `gitpoulpi sparse-checkout status | set | add | disable`（[CLI リファレンス](cli-reference.md)を参照）。MCP サーバーにも同じツールがあります。
