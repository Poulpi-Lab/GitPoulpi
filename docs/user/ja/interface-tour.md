# インターフェースツアー

このページでは、GitPoulpi のウィンドウの各エリアを上から順に名前を挙げて説明します。
ほかのページも同じ名前を使っています。画像には、架空の作成者を使った小さなデモ用リポジトリを使っています。

![主なエリアを示したメインウィンドウ：タブバー、ツールバー、Refs サイドバー、ログ、作業中の変更ペイン、commit フォーム、ステータスバー](../images/hero.png)

## フレーム

### タイトルバー

ウィンドウの上端には
`🐙 GitPoulpi vX.Y.Z -- <リポジトリのパス>` と表示されます（セッション名は、既定では下端にあるステータスバーに表示されます）。

- **🐙** をクリックすると **GitPoulpi について** ウィンドウが開きます。バージョン、ビルドの機能、ライセンス、リンク、サードパーティの crate が表示されます。画像を描画できるターミナルでは、タコはピクセルロゴになり、ロゴの色で表示されます（それ以外では絵文字のままです）。パレット：`ヘルプ: GitPoulpi について`。キー：`Ctrl+N` の後に `A`。このウィンドウでは、タコの瞳がマウスポインターを追いかけます。ロゴをクリックする（または `Space` を押す）と、ロゴが回転して次の色に変わります。ロゴを右クリックする（または `c` を押す）と色の一覧が開きます。選んだ色は `ui.logo_color` に保存されます。リンクはクリックするか、アクセスキー（`s` ソースコード、`d` ドキュメント、`i` ライセンス）で開けます。`l` ではサードパーティの crate がバージョンとライセンスつきで一覧されます（スクロールできる一覧です。`Esc` または `l`、あるいは見出しのクリックで戻ります）。一覧の各 crate には、そのページへのリンク（リポジトリ、なければ crates.io のページ）が付いています。行をクリックするか、`↑` `↓` で選んで `Enter` を押すと、ブラウザーで開きます。 `t`（またはパレットのコマンド `ヘルプ: ライセンスとクレジット`）で、プログラムに組み込まれているすべてのもののライセンス表記とクレジットを、スクロールできるテキストで読めます（`Up` / `Down`、`PgUp` / `PgDn`、`Home` / `End`。`Esc` または `t` で戻ります）。スクリプトからは `gitpoulpi licenses` が同じテキストを出力します。
- 名前とパスの間にある**バージョン**（`v1.0.0`。新しいリリースがあれば `vX.Y.Z が利用可能`）をクリックすると、**リリースノート** タブが開きます。[更新](updates.md)を参照してください。
- パスのすぐ右にある **開く場所 ▾** は、タブのフォルダーをターミナル、エディター、マルチプレクサ、ファイルマネージャーのいずれかで開きます（`Alt+O`）。[開く場所](open-in.md)を参照してください。
- 歯車のすぐ左にある **⌕ 全体検索**（虫眼鏡とラベル）で[全体検索](search.md)が開きます（`Ctrl+Alt+F`）。タイトルバーが狭すぎるときは、これが最初に省かれます。まずラベルが消え（虫眼鏡は残ります）、次にボタンが消えます。
- **×** のすぐ左にある**歯車**（`⚙`）で**設定**が開きます（`Ctrl+,`）。
- 右端の **×** は `q` と同じく終了します。

![メインウィンドウの上に開いた「GitPoulpi について」ウィンドウ：ピクセルのタコ、バージョン、ライセンス、ビルドの機能、リンク](../images/about.png)

![「GitPoulpi について」ウィンドウのサードパーティの crate の一覧：各行に名前、バージョン、crate のページへのリンク、ライセンス](../images/about-crates.png)

### ステータスバー

既定ではウィンドウの最終行です。**設定 > 外観 > ステータスバーの位置**で、リポジトリのタブの上の最上部に移せます。

下端には、現在のブランチ、読み込み済みの commit 数、`dirty` または `clean`、セッション名、そして最もよく使うキーが表示されます。`?` ヘルプ、`Ctrl+G` git 操作、`Ctrl+N` ナビゲーション、`Ctrl+P` コマンド、`Shift+F10` メニュー、`q` 終了です。ウィンドウが狭いときは、重要度の低いキーから省かれます。ステータスバーにはステータスメッセージや進行状況も表示されます。表示されるキーは常に実際に有効なキーで、変更したキーも反映されます（[設定](settings.md#キーボードとマウス)を参照）。

commit 数は、古い履歴がまだ読み込まれていない間は `500 / 48213 commits` と表示され（総数を数えている間は `500 / … commit`）、すべて読み込まれると `2500 commits` だけになります。スパースチェックアウトでは、セッション名の後ろに `スパース` バッジが付きます。総数の数え方は設定です：**commitsの総数の数え方**（[設定](settings.md#ログとグラフ)を参照）。

ステータスバーの右端にある **アクティビティ** ボタンで、アクティビティログが開きます。Git 操作タブ（操作と所要時間、メッセージ、エラー）、アプリケーションタブ（レベルボックスと **ログを消去** ボタンつきのアプリケーションログ）、そして両方をこのリポジトリ、ワークスペース、すべてのリポジトリのいずれかに絞り込む **対象範囲** ボックスがあります。ボタンの数字は、まだ見ていないエラーの数です。操作が失敗すると、ステータスバーが赤で理由を伝えます。クリックすると、アクティビティログのその項目が開き、次の一手、詳細、AI 向けのコピーが表示されます。どちらも[何かが失敗したとき](troubleshooting.md#何かが失敗したとき)で説明しています。

**アプリケーション** タブでは、**ログを消去**（`x`）が確認の後にアプリケーションログのファイルを空にします。**アクティビティ** ボタンの左のジョブ表示は、実行中のバックグラウンドジョブと、それを中止する `[x]` を表示します。ホームタブにも同じステータスバーがあり、右下に **アクティビティ** ボタンがあります（すべてのリポジトリで開きます）。

### オーバーレイ

コマンドパレット、ヘルプ、コンテキストメニュー、ダイアログ、ポップアップ、設定は、ウィンドウの上に重ねて開きます。どれも枠の右上に `✕` があり、`Esc` または `✕` のクリックで閉じます。ダイアログ、ポップアップ、パネルは、外側をクリックしても閉じます（[ウィンドウとダイアログを閉じる](mouse-and-gestures.md#ウィンドウとダイアログを閉じる)を参照）。

## タブ行

左端に **ホーム** タブ（家のアイコン）があり、その右に[ワークスペースのチップ](workspaces.md)（ワークスペースがあるとき）、固定の **Radar** タブ（ほかのタブと同じように閉じられます。[Radar](radar.md)を参照）、そして一度開いた後は **ワークスペース** タブ（`Alt+J`。ほかのタブと同じように閉じられます）が続きます。その右に、開いているリポジトリごとに 1 つずつタブが並びます。タブを閉じる `x` は、選択中のタブとポインターの下のタブにだけ表示されます。タブ行にはタブしかありません（[全体検索](search.md)のボタンはタイトルバーにあります）。

**設定 > 外観 > タブバーの位置** で、この行をウィンドウの下端（ステータスバーの下）へ移すか、左端の列にできます。列では 1 行に 1 タブで、先頭がホーム、次にワークスペースのチップ、Radar、ワークスペースのタブ、各タブ（長い名前は `…` で終わります）、そして `+` が並びます。タブが行数を超えると、`…` の行が上（`▲`）と下（`▼`）に隠れた数を示し、タブ一覧を開きます。ホイールで列がスクロールします。縦のツールバーの横でも、タブが一番外側です。80 列未満のウィンドウではタブは上に残ります。クリック、閉じる×、中クリック、右クリックメニュー、ドラッグによる並べ替え、キーボードは、どの位置でも同じように動きます。

- 最後のタブのすぐ右にある **+** で小さなメニューが開きます：**新しいタブ**（`Alt+T`、パレットの **タブ: 新しいタブ**）と、それぞれのタブが閉じている間は **Radar** と **ワークスペース**（`Alt+J`）で、これらはそのタブを開きます。パレットの **タブ: 新規...** でも同じメニューが開きます。**新しいタブ**とは、
  検索フィールドが準備された状態のホーム画面のことで、入力するとすぐにリポジトリが絞り込まれます。
  リポジトリを選ぶ（または参照、クローン、初期化を行う）と、そのタブがバーの末尾に現れます。すでに開いているリポジトリなら、そのタブに切り替わるだけです。
  空の検索での `Esc`、`Ctrl+W`、その `x`、またはマウスの中クリックで新しいタブが閉じ、元のタブに戻ります。セッションに保存されることはありません。

  ![新しいタブ：検索フィールドが準備されたホーム画面が、開いているタブの上に表示されている](../images/new-tab.png)
- タブを右クリックするか `Ctrl+T` を押すと、タブメニューが開きます：**新しいタブ**、**タブを閉じる**、**ほかのタブを閉じる...**、**右側のタブを閉じる...**、**お気に入りに追加**（または **お気に入りから削除**）、**ワークスペースに追加**（ワークスペースがあるときは **ワークスペースから削除** も）、**パスをコピー**、**開く場所 ›**、**SSH 鍵...**、**スパースチェックアウト...**。
- `Ctrl+PageUp` と `Ctrl+PageDown` でタブを切り替えます。`Ctrl+W` で現在のタブを閉じます。タブを中クリックしても閉じます（同じ確認が表示されます）。
- `t`（または `Ctrl+N t`）でタブピッカーを開きます。開いているタブを検索できる一覧です。
- **タブの並べ替え：**リポジトリのタブを押したまま横にドラッグします（タブの影がポインターに付いてきて、バーが置き場所を示します。`Esc` で取りやめ）。タブピッカーの行をドラッグする、ピッカーで強調表示した行で `Alt+Up` / `Alt+Down` を押す、パレットの **タブ: 左へ移動** / **タブ: 右へ移動** を実行する、のいずれでも並べ替えられます。順序はセッションと一緒に保存されます。動かさずにクリックしただけなら、ふつうにタブを選択します。家、ワークスペースのチップ、`+` は動きません。
- **終了して cd** は、シェルラッパー `gp` 経由で GitPoulpi を起動し、かつタブが起動したフォルダーと異なるときに、タブの右側に表示されます。[タブのフォルダーに追従する](following-the-tab-folder.md)を参照してください。
- 家のアイコンのすぐ右にある**ワークスペースのチップ**（色付きのドットと名前、または「ワークスペースなし」）で、[ワークスペース](workspaces.md)を切り替えます。
  クリックするか `Alt+W` を押します。ワークスペースが 1 つでもあると表示されます。

![開いているリポジトリを一覧表示したタブピッカー](../images/tab-picker.png)

**タブを記憶**がオン（既定）のとき、次回の起動時にタブが復元されます。worktree は専用のタブで開き、worktree を削除するとそのタブも閉じます。

worktree のタブは、そのリポジトリのタブのすぐ後ろに置かれ、離したタブも元の位置に戻ります（設定 > 一般 の **worktree のタブをまとめる**、既定でオン）。

### ホーム

ホームタブはリポジトリマネージャーです。**開いているリポジトリ**、**お気に入り**、**最近のリポジトリ**、**すべてのリポジトリ**の 4 つのセクションがあります。各行には、ブランチ、先行/遅れの数、変更数が表示されます。各行には、星（お気に入り）、**開く** または **切替**、**閉じる** または **削除**、そして `⋮` メニューがあります。

上部には、**参照**、**クローン**、**初期化**、検索ボックス、**すべて折りたたむ**、**すべて展開**があります。存在しなくなったフォルダーは、*最近* と *すべて* から自動的に消えます。見つからないお気に入りは残り、**削除**ボタンが表示されます。**削除**してもディスク上のものは何も消えません。

キー：`Enter` 開く、`f` お気に入り、`x` 閉じる/削除、`.` メニュー、`/` 検索、`Space` セクションの折りたたみ、`Esc` 自分のタブに戻る。
`Ctrl+N` を押すと、検索ボックス、各セクション、各ボタンにバッジが表示されます。バッジの文字を押すと、そこにフォーカスするか、そのボタンを押します（[バッジ](keybindings.md#バッジ) を参照）。

検索ボックスは 1 つで、その下のすべて（お気に入りを含む）を絞り込みます。名前、ブランチ、パスのいずれかが入力した文字を含むリポジトリが残ります。ワークスペースはホームのページではなく専用のタブです。`+` メニュー、`Alt+J`、またはコマンドパレットから開き、`x` で閉じます。[ワークスペース](workspaces.md)を参照してください。

**クローン** には、接続済みのプロファイル（GitHub、GitLab、Gitea、Forgejo、Azure DevOps、Bitbucket、Gerrit）ごとに、アクセスできるリポジトリが所有者ごとのセクションで一覧されます。最初が自分のもの、その後に組織またはグループごとのセクションが（アルファベット順に）続き、それぞれ見出しの下に並びます。鍵のマークは非公開のリポジトリを示します。検索ボックスはすべてのセクションを横断して絞り込み、一致のないセクションは消えます。`Up` と `Down` は見出しを飛ばし、`Home`、`End`、`PgUp`、`PgDn` も一覧で使えます。

![ホームタブ：開いているリポジトリ、お気に入り、最近のリポジトリと、参照・クローン・初期化のボタン](../images/home.png)

## ツールバー

既定では、ペインの下でステータスバーの上にある行です。**設定 > 外観 > ツールバーの位置**で、上（タブの下）、下、またはペインの左右の列に置けます（80 列未満のウィンドウでは、列は下の行として描画されます）。ボタンは行または列の先頭に並びます。**設定 > 外観 > ツールバーのボタンの配置**で中央または末尾に寄せられます。各ボタンのアイコンの色はテーマで決まります（[テーマ](themes.md)を参照）。すべては収まらないとき、重要度の低いボタンが `⋯` の奥にまとめられます。列では各ボタンが 1 行を使い、`▾` は行の末尾に付き、メニューは列の横に開きます。下のツールバーのメニューは上向きに開きます。

| ボタン | 動作 |
|---|---|
| **元に戻す**、**やり直す** | 直前の操作を取り消す、またはやり直します（`Ctrl+Z`、`Ctrl+Y`）。元に戻す機能がオフのときは非表示です。[元に戻す/やり直す](undo-redo.md)を参照。 |
| **Pull** `▾` | **設定 > Git とエンコード > pullボタン**の指定どおりに pull します。`▾` の一覧には **Fetch All**、**Pull（可能なら早送り）**、**Pull（早送りのみ）**、**Pull（rebase）** があります。一覧の項目は 1 回だけ実行され、ボタンの設定は変わりません。 |
| **Push** `▾` | チェックアウト中のブランチを push します。`▾` の一覧では、選んだリモートへ 1 回だけ push します。 |
| **ブランチ** | チェックアウト中の commit にブランチを作成します。 |
| **Tag** | チェックアウト中の commit に tag を作成します。 |
| **Stash**、**Pop** | すべての変更を stash します。最新の stash を pop します。 |
| **LFS** `▾` | Git LFS の操作：fetch、チェックアウト、pull、push、prune（`Ctrl+G l`）。Git LFS がオフのときは非表示です。[Git LFS](lfs.md)を参照。 |
| **Flow** `▾` | ブランチワークフローのメニュー（開始、完了、同期、昇格。`Ctrl+G Shift+W`）。ワークフローがあるリポジトリでだけ表示されます。[ブランチワークフロー](branching-workflows.md)を参照。 |
| **検索** | ログの上に commit 検索バーを開きます（`f`）。 |

末端（行では右端、列では下端）には、リポジトリがホストにリンクされている場合、**チップ**が表示され、チェックアウト中のブランチの pull request（例：`GH #12` や `GL !53`）、または薄い `+ PR` を示します。**設定 > 外観 > pull request ボタンを末尾に固定**（既定でオン）で末端に固定され、オフにすると他のボタンと一緒に並び、同じ配置になります。[ホスティングと Issue トラッカー](hosting-integration.md)を参照してください。列では、プロファイルのコンボボックスが最後の行を使います。

右端には、[プロファイル](settings.md#プロファイル)が 2 つ以上あるとき、**プロファイルのコンボボックス**が表示され、このリポジトリの commit の作成者 ID を選べます。最初の行の*既定*は**設定 > プロファイル**に従います。プロファイルを選ぶと、GitPoulpi は、その名前とメールアドレスをリポジトリの git 設定（`user.name`、`user.email`）にも書き込むかどうかを尋ねます。**git 設定に書き込む**で書き込みます。`Esc` を押すと、選択は GitPoulpi の中だけに保たれます。パレット：`リポジトリ: プロファイルを変更...`。

すべてのボタンに、パレットコマンドとショートカットがあります。

![ツールバーの下に開いた Pull の一覧：Fetch All と 3 通りの pull 方法](../images/pull-push-tooltip.png)

## バナー

ログの上の帯が、リポジトリが特別な状態にあることを知らせます。先に進むためのボタンが付いており、各ボタンはパレットコマンドにもなっています。

| バナー | ボタン |
|---|---|
| merge、cherry-pick、revert が競合で停止した | **競合を解決...**、**Commit** または **続行**、**中止** |
| rebase の進行中 | **競合を解決...**、**続行**、**スキップ**、**中止** |
| **パッチを適用中（git am）** | **競合を解決...**、**続行**、**スキップ**、**中止** |
| 残った `index.lock` がすべての変更を妨げている | **index.lock を削除**（先に確認します） |
| 自動 stash が戻されていない | **Pop now**、**Show stash**、**やり直す**、**Drop**（状態によって選択肢が変わります） |

[merge 競合の解決](merge-conflicts.md)と[トラブルシューティング](troubleshooting.md)を参照してください。

## Refs サイドバー（左）

commit に名前を付けるものすべてを木構造で表示します。各セクションのタイトルには件数、折りたたみ用のシェブロンがあり、スクロール位置もセクションごとに独立しています。2 つのセクションの境界をドラッグすると、サイズを変えられます。

- 上部の**絞り込み**ボックス（`/`）：すべてのセクションを名前で絞り込みます。
- **ローカル**: 自分のブランチです。`/` で区切ったフォルダー（`feature/`、`fix/`）にまとめられます。チェックマークがチェックアウト中のブランチを示します。フォルダー表示は設定でオフにできます。
- **リモート**: 各リモートと、その下のブランチ。
- **WORKTREE**: リンクされた worktree（ある場合）。ダブルクリックすると専用のタブで開きます。
- **STASHES**: stash の一覧。右クリックすると **Pop（復元して削除）**、**Apply（stashを残す）**、**Drop** が使えます。
- **TAGS**: tag の一覧。ブランチと同じく `/` でフォルダーに分かれます（`releases/`、`backups/` など）。矢印は、その tag がリモートにもあることを示します。
- **PULL REQUESTS** と **ISSUES**: ホスティングアカウントを接続し、リポジトリをリンクした後に表示されます。
- **サブモジュール**: サブモジュールとその状態（ある場合）。[サブモジュール](submodules.md)を参照。

**セクションの表示と非表示：** セクションの見出し、またはペインの空いている部分を右クリックすると、セクションのチェックリストが開きます（最後に残った表示中のセクションは外せません）。選択はリポジトリごとに保持され、再起動後も残ります。[左ペインのセクション](mouse-and-gestures.md#左ペインのセクション)を参照してください。

行にカーソルを合わせるとボタンが表示されます。参照をログで非表示/表示するボタンと、**ソロ表示**（その参照の commit だけを表示）です。ローカルブランチまたは tag をダブルクリックするとチェックアウトします。行を右クリックするとメニューが開きます。サイドバーのタイトルにある `‹` でサイドバーを折りたたみます（`Ctrl+N h`）。

2つのサイドペイン（Refs サイドバー `Ctrl+N h` と右ペイン `Ctrl+N l`）はログに属します。diff、ファイルビュー、エディターを開いている間にどちらかを表示または折りたたむと、そのビューだけに適用されます。diff やファイルビューでは、内容の表示領域を確保するため、Refs サイドバーが自動的に折りたたまれます。ログに戻ると、両方のペインはログで最後に設定した状態のままで、それが次回の起動用に保存される状態です。

## ログ（中央）

![ログ：列のヘッダー行、一番上の作業中の変更の行、stash の行、グラフの左側の参照ピル](../images/log-graph.png)

1 行が 1 commit で、新しいものが上です。ヘッダーを右クリックすると列の表示/非表示を選べます。2 つのヘッダーの境界をドラッグすると列幅を変えられ、ヘッダーをドラッグすると列を移動できます。

このペインにはタイトルがなく、列見出しがそれを示します。tag は実際の位置に描かれ、仮表示されることはありません。ref のない commit では、ホバー中の行に所属ブランチの名前が淡いピルで表示されます。そのブランチが削除されている場合は、取り消し線付きのピルに、merge した merge commit から読み取った名前が表示されます（設定 > ログとグラフ の **ホバー中のcommitに、ブランチの仮表示を出す** で無効にできます）。

| 列 | 内容 |
|---|---|
| **Ref** | commit 上のブランチと tag を示す色付きのピル。ノートパソコンのアイコンはローカル、地球儀はリモート、tag アイコンは tag、ほかにも参照がある場合は `+N` です。 |
| **Graph** | ブランチのレーン、merge、分岐点。kitty、Ghostty、WezTerm、iTerm2、sixel 対応の Windows Terminal と foot では画像として、そのほかのターミナルでは文字で描かれます。レーンの色はテーマ、または選んだパレットで決まります（[テーマ](themes.md)を参照）。最小の幅（commit の点 1 つ分）では列はコンパクトになり、すべての commit が 1 本のレーンに並び、ブランチや merge の線は描かれません。 |
| **概要** | commit の概要（1 行目）。 |
| **作成者** | 作成者。アバターを併せて表示できます。 |
| **日付** | 作成日。形式は選べます。 |
| **変更** | 任意：変更されたファイル数と `+追加 -削除` の行数。 |
| **SHA** | 短いハッシュ。 |

![ログヘッダーの列メニュー：Ref、Graph、概要、作成者、日付、変更、SHA のチェックボックス](../images/log-columns-menu.png)

特別な行：

- 一番上の**作業中の変更の行**（WIP 行）：破線の丸、`// WIP` または下書きのメッセージ、変更/追加されたファイル数。クリックすると、右ペインでステージと commit ができます。
- **stashの行**: stash を作成した commit の隣のレーン上にある小さな四角。
- 検索中は、一致しない行が暗く表示されます。

セルにカーソルを合わせると、全文のツールチップが表示されます。行を右クリックすると [commit メニュー](log-and-history.md#commit-メニュー)が開きます。

![commit の右クリックメニュー：cherry-pick、revert、reset、メッセージの編集、説明、rebase、ブランチ、tag、チェックアウト、worktree、パッチ、コピーの各操作](../images/context-menu.png)

## 右ペイン

右ペインはログの選択に追従します。

**作業中の変更**（WIP 行を選択しているとき）：

- `4 file changes on main` のようなタイトル。merge が競合している間は、競合しているファイル数も加わります。左側の赤い `[✖]` はすべての変更を破棄します（先に確認します）。AI がオンのとき、右側の `[✦]` で変更を説明できます。
- **パス** または **ツリー**（フラットな一覧かフォルダー表示、`m`）、**すべて折りたたむ**、**すべてのファイルを表示**（`a`）。
- **未ステージのファイル** と **ステージ済みのファイル**。それぞれに件数と、**すべての変更をステージ** または **すべてステージ解除** のボタンがあります。行にカーソルを合わせると、**ファイルをステージ** または **ファイルをステージ解除** ボタンが表示されます。
- 下部の **commit フォーム**: **直前のcommitを修正（Amend）**、**AI でcommitを構成**（AI がオンのとき）、文字数カウンター付きの**概要**と `✦` ボタン、**説明**、そして **N ファイルの変更をcommit**ボタン。

**commit の詳細**（commit を選択しているとき）は上から順に：完全なハッシュ、アバターと日付付きの作成者、親のハッシュと変更数、そしてメッセージ（概要と説明。下端をドラッグするとサイズを変えられます）。その下の**変更されたファイル**のペインは、専用のコントロールで始まります：並べ替えの切り替え、**パス** / **ツリー**、**すべてのファイルを表示**、**ファイルを絞り込み：**の入力ボックス。これらは一覧の上に固定され、スクロールするのは一覧だけです。ファイルをクリックすると、その diff が開きます。ウィンドウの高さが足りないときは、まずメッセージが（1 行まで）縮み、次に一覧が縮みます。作業中の変更のビューでは、**パス** / **ツリー** / **すべてのファイルを表示**の行はファイル一覧の上端、未ステージとステージ済みの一覧の上にあります。

すべてのファイル一覧には、ファイル、フォルダー、空白部分のメニューがあり、複数のファイルを同時に選択できます（**Ctrl+クリック**、**Shift+クリック**）。[ステージと commit](staging-and-committing.md)を参照してください。

## Commit列

commit のファイルが diff、ファイルビュー、Blame で開いているとき、その左に 1 つの列を置けます（作業コピーを編集する内蔵エディターの横には置けません。エディターを開くと列は消え、エディターを閉じて diff に戻ると復活します）。状態は 3 つです。

- **ファイル**: そのファイル 1 つの commit を 2 行ずつ並べます（[ファイル履歴](log-and-history.md#ファイル履歴)）。右側には、選択した commit 時点のファイルが表示されます。
- **すべて**: ログの commit のコンパクトな一覧とそのグラフです。以下で説明します。
- **非表示**: ビューの左端にある細い `›` のストリップで列を戻せます（ツールチップにキーが表示されます）。

ビューのボタンバーは常に列の上で全幅に広がるので、列を開いても閉じても、一覧を切り替えても、ボタンは動きません。バーの **`ファイル │ すべて`** の切り替え（1 つのコントロールの 2 つの部分で、幅は常に同じ）で一覧を選びます。部分をクリックするとその一覧が表示され、列が非表示なら開きます。列の表示中に、すでに選択されている部分をクリックすると列が隠れます。表示中の一覧の部分が点灯し、列が非表示の間は、戻したときの一覧の部分に下線が付き、一覧は保持されます。ツールチップには、クリック、選択中の部分の再クリック、`Alt+C` が表示されます。ファイル履歴は、従来どおりファイルのメニューやパレットの `ファイル履歴: ...` からも開きます。

![ファイルの commit の diff の横にある、すべて状態の commit 列。ヘッダーは Ref、グラフ、概要、作成者、日付で、Ref の欄にブランチとタグのラベルが表示されている](../images/commit-column-all.png)

- **表示と非表示**: `Alt+C`（パレットの `表示: Commit列を切り替え`）、切り替えで選択中の部分をクリック、列の ✕、または `›` のストリップ。パレットでは `表示: Commit列: 非表示`、`...: ファイル履歴`、`...: すべてのCommits` で状態を選べます。選択は、そのときの一覧とともに、列のほかの設定と一緒に記憶されます。選択がなければ、すべての一覧はターミナルの幅で決まり、幅 140 列以上で表示されます。隣のビューが 30 列未満になる場合は列を描画しません。作業ツリーの diff と比較では、すべての一覧のグラフを描画しません（ファイル履歴は commit を必要としないので表示されます）。
- **幅**: 右の枠線をドラッグする（光る枠線がポインターに追従します）か、`表示: Commit列を広げる` と `表示: Commit列を狭める` を使います。中央の列の最大 70% まで広げられます（残りはビューのもので、ビューが 30 列未満になることはありません）。ほかのサイズと一緒に記憶されます。
- **commit を選ぶ**: クリックするか、列にキーボードを渡して（`Ctrl+N` の後に列のバッジ、または `表示: Commit列にフォーカス`）、`上` / `下`、`PageUp` / `PageDown`、`Home` / `End` を使います。`Enter` または `右` でその commit のファイル一覧へ進み、`Esc` でキーボードをビューに戻します。右ペインは選択に追従し、commit の詳細と変更されたファイルを表示するので、その commit の別のファイルも開けます。
- **ビューの動き**: 開いているファイルは開いたままです。選んだ commit がそれを変更していれば、その commit での diff を表示します。変更していなければ、そのときのファイルをタイトルに「この commit では変更なし」と付けて表示します。その commit にそのファイルがなければ、ビューがそう伝え、そのまま使えます。Blame は Blame のまま、選んだ commit 時点のものになります。

すべての一覧の上にはヘッダー（ログ自身の列名）があります。1 行に 1 commit で、グラフのレーン、タイトル（メッセージ）、作成者の名前、短い日付を表示し、オンにするとブランチとタグのラベルも表示します。ログ自身の一覧と同じ commit が同じ順序で並び、スクロールに合わせて古いものを読み込みます。レーンはログの Graph 列と同じように描かれます。画像を表示できるターミナル（[ターミナルの選び方](terminals.md)を参照）では、つながったレーンと丸いマーカーとして描かれ、アバター設定が Graph のときは円の中に作成者の画像も表示されます。それ以外では文字で描かれます。既定では、レーンは必要な幅を取り、タイトルには常に数語分の幅が残ります。列が狭いときは、レーンが切り詰められる前に、作成者、次に日付が省かれます。最小の幅（commit の点 1 つ分）まで縮めると、グラフの欄はログと同じくコンパクトになり、すべての commit が 1 本のレーンに並んで、ブランチや merge の線は描かれません。ペインに切られた欄（横にスクロールした行や、余白より広いグラフの欄）は、端で切れたまま画像とアバターを保ちます。ホイールはポインターの下の一覧をスクロールします。

- **ホバーとメニュー**: 行にポインターを置くと、その下の部分についてログと同じツールチップが表示されます（タイトルではメッセージ全体、作成者の名前とメールアドレス、完全な日付）。行を右クリックする（列がキーボードを持っているときはメニューキーまたは `Shift+F10`。パレットでは `表示: Commit列: 選択行のメニュー`）とメニューが開きます：*Log で表示*、その commit でのファイルの diff、その commit 時点のファイル、その commit 時点のファイルの Blame、続いてその commit に対するログ自身のメニュー（コピー、cherry-pick、ブランチ、区切り線の下に revert など履歴を書き換える項目）。最初の 4 つの項目には、パレットの項目もあります（`表示: Commit列: ...を表示` など）。ファイルの一覧では、行にファイル履歴自身のメニューと同じツールチップがあります。
- **欄の幅と横スクロール**: ヘッダーの境界をドラッグすると、その左にある欄（レーン、メッセージ、作成者、日付、Ref、変更、SHA）の幅を変えられます。最後の欄にも境界があります。その直後のセル（行が余白いっぱいのときは列自体の枠線）で、同じように光り、最後の欄の幅を変えます。ログ（`ui.column_resize`）と同じく、境界は既定では 2 つの欄の間の区切りセルで、Graph の行の色づけがそこで終わります（色づけは区切りを通り抜けるので、区切りと次の欄の間に何もないセルは挟まりません）。ヘッダーではそこに目印が置かれ、ポインターが乗っている間、またはドラッグ中は列に沿って細い線が描かれ、線上のどこからでもドラッグしてサイズを変えられます。`header` では次の名前の先頭の文字が境界で、ポインターが乗っている間は光ります（線は描かれず、ドラッグできるのはヘッダーだけです）。何も調整していない間は、メッセージが他の欄の残りを使います。最初のドラッグで、メッセージを含むすべての欄がそのときの幅に固定されるので、1 つの欄を調整するとその後ろの欄が動き、ほかの幅は変わりません。幅を変えた欄は保たれ、スペースのために縮められることはありません。そのため行が列より広くなったときは、Shift+ホイール、横ホイール、または列がキーボードを持っているときの `Shift+Left` / `Shift+Right` で横にスクロールし、下端の枠線のスクロールバーが位置を示します。キーボードでは、`Tab` で（表示中の欄から）欄を選び、`]` で広げ、`[` で狭め、`0` ですべての欄を自動の幅に戻します（パレットには `表示: Commit列: 次の欄の幅を調整`、`... 欄を広げる`、`... 欄を狭める`、`... 各欄の幅をリセット`、`... 左へスクロール`、`... 右へスクロール` があります）。幅は記憶されます。スクロールでレーンが切れている間は、画像を表示できるターミナルでもレーンは文字で描かれます。
- **欄の選択**: ヘッダーを右クリックすると、欄ごとにチェックボックスのあるメニューが開きます。ログが持つすべての列、つまり Ref、グラフ、概要、作成者、日付、変更、SHA です。概要は常に表示されます。**Ref**、**変更**、**SHA** は既定でオフです。表示すると、Ref はその commit のブランチとタグのラベルを、変更はファイル数と `+追加 -削除` の行数を、SHA は短いハッシュを、いずれもログ自身の列と同じように示します。Ref と同じく、変更と SHA も余白のために縮められることはなく、代わりに行が横にスクロールします。キーボードでは、`表示: Commit列: 列を選択` が同じメニューを開き（矢印キーと `Enter` で行を選びます）、`表示: Commit列: Ref を切り替え`、`... グラフを切り替え`、`... 作成者を切り替え`、`... 日付を切り替え`、`... 変更を切り替え`、`... SHA を切り替え` で欄をすぐに切り替えられます。表示する欄、その順序、幅はこの列だけのもので、`config.toml`（`ui.commit_column_columns_visible`、`ui.commit_column_columns_order`、`ui.commit_column_columns_widths`）に保存され、ログ自身の列とは別で、どちらも他方を変えません。

  ![commit 列のヘッダーを右クリックしたメニュー：Ref、グラフ、概要（常に表示）、作成者、日付、変更、SHA のチェックボックス](../images/commit-column-menu.png)

- **欄の移動**: ヘッダーの名前を別の名前の上へドラッグすると、その欄をそこへ移動できます。ログと同じです（行はポインターに追従します。`ui.column_resize = "header"` では名前の先頭の文字がサイズ変更の境界なので、名前の残りの部分を押してください）。どの欄もどこへでも動かせ、レーンと Ref のラベルも含みます。キーボードでは、`Tab` で欄を選び、`<` / `>` で表示中の欄の中で 1 つ左または右へ動かします（パレットには `表示: Commit列: 欄を左へ移動` と `... 欄を右へ移動` があります）。順序は記憶されます。

マウスの操作は[マウスとジェスチャー](mouse-and-gestures.md#commit列すべての一覧)にも載っています。

## サイズは記憶されます

GitPoulpi は、ドラッグしたサイズをすべて、タブの切り替えや再起動をまたいで保持します。サイズはすべてのリポジトリで共通です。対象は、Refs サイドバー・ログ・右ペインの間の区切り、各 Refs セクションの高さ、commit メッセージのブロック、ログの列幅、merge エディターのペイン、フォルダーピッカーの区切りです。サイズはウィンドウに対する割合で保存されるため、広いターミナルで作ったレイアウトは狭いターミナルにも収まります。

すべてのサイズをリセットするには、パレットコマンド `ナビゲーション: レイアウトをリセット` を実行します。一部のサイズには個別のリセットもあります。`ナビゲーション: Refs のセクションサイズをリセット`、`Commit詳細: メッセージのサイズをリセット`、merge エディターでは区切りのダブルクリックまたは `Alt+0` です。

## オーバーレイと特別な画面

- **コマンドパレット**（`Ctrl+P`）：すべてのコマンドを絞り込めるボックスです。各行にショートカットが表示されます。今は実行できないコマンドはグレーになり、理由が下部に表示されます。コマンドには `Git:`、`Refs:`、`ナビゲーション:`、`Diff:`、`作業中の変更:`、`Commit:`、`表示:`、`リポジトリ:`、`タブ:`、`LFS:`、`Pull Request:`、`Issue:`、`AI:` のようなグループ接頭辞が付いています。接頭辞を入力すると、そのグループが表示されます。
- **ピッカー**: 一部のパレットコマンドは 2 つ目の一覧を開きます。たとえば `アプリ: テーマを変更...`、`アプリ: 言語を変更...`、`アプリ: グラフのカラーテーマを変更...` です。一覧を移動するたびに、ウィンドウに各候補がその場で反映されます。`Enter` で確定し、`Esc` で元の選択に戻します。テーマの一覧には**すべて**、**ダーク**、**ライト**、**カラー**のフィルターがあります。[テーマ](themes.md)を参照。
- **ヘルプ**（`?`）：タブで構成されています。**キー** タブはすべてのキーとジェスチャーを一覧表示し、ほかのタブ（開始、ログ、変更、Refs、ホスティング、設定、AI/CLI）は各アクションとその呼び出し方を短くまとめたガイドです。タブは `Tab` / `Shift+Tab`、`Left` / `Right`、`Alt+1`..`Alt+8`、またはクリックで切り替えます。入力すると現在のタブを絞り込めます。`Ctrl+D`、または下部のリンクをクリックすると、表示中のタブに対応するドキュメントのページが開きます。

  ![ヘルプのホスティングタブ：各アクションとその呼び出し方をまとめた短いガイド](../images/help-hosting.png)

  ![ヘルプオーバーレイ：Ctrl+P、Ctrl+N、Ctrl+G、?、移動キーを並べた Global セクションと、続くマウスの基本のセクション](../images/help.png)
- **検索バー**（`f`）：ログの右上にあります。`n of N` の形で一致数が表示されます。
- **コンテキストメニュー**: 右クリック、または選択した行で `.` を押します。`›` のある行はサブメニューを開きます。
- **ダイアログ**: 確認、ブランチ名や tag 名、クローン、初期化、Pull Request の作成、push が拒否された後の選択肢など。`Enter` で決定、`Esc` でキャンセルします。
- **インタラクティブ rebase** と **commitコンポーザー**は、ログを確認用の画面に置き換えます。[ログを使う](log-and-history.md#インタラクティブ-rebase)と[ステージと commit](staging-and-committing.md#commit-コンポーザー変更を複数の-commit-に分ける)を参照してください。

  ![4 件の提案された commit をレビューする commit コンポーザー。各 commit にファイルが付き、リセット、キャンセル、commit 4 件を作成のボタンがある](../images/composer.png)

- **設定**（`Ctrl+,` または歯車）：左にページの一覧、右にそのページの項目が並びます。[設定](settings.md)を参照。

  ![設定：左に検索ボックス付きのページ一覧、右に一般ページ](../images/settings.png)

- 長い応答用の**ポップアップ**。たとえば AI の**変更の説明**ポップアップ（`↑` `↓` でスクロール、`c` でコピー、`Esc` で閉じる）。

  ![AI による説明と、再確認すべき点の一覧を表示した、作業中の変更の説明ポップアップ](../images/ai-explain.png)

ポップアップ内の一覧はすべて同じように操作できます。[キーバインド](keybindings.md)と[マウスとジェスチャー](mouse-and-gestures.md)を参照してください。

## このドキュメントで使う用語

| 用語 | 意味 |
|---|---|
| ペイン | 3 つの列のひとつ：Refs サイドバー、ログ（または開いているファイル）、右ペイン。 |
| ピル | Ref 列にあるブランチまたは tag のラベル。 |
| WIP 行 | ログの一番上にある作業中の変更の行。 |
| ハンク | diff の中の、変更された行のひとまとまり。 |
| コンポーザー | commit フォーム、および変更を複数の commit に分ける AI レビュー。 |
| コード（chord） | あるキーの後に別のキーを続けて押す操作。たとえば `Ctrl+G` の次に `s`。 |
| 接頭辞 | `Ctrl+G`（git 操作）または `Ctrl+N`（ナビゲーション）。 |
| バッジ | `Ctrl+N` がコントロールの横に表示する文字。押すとそのコントロールにフォーカスします。 |
