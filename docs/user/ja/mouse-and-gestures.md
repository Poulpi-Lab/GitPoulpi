# マウスとジェスチャー

マウスでできることには、すべてキーボードでの代わりがあります。[キーバインド](keybindings.md)を参照してください。各エリアの名前は[インターフェースツアー](interface-tour.md)にあります。

## 一般的なルール

- 行を**クリック**すると選択します。すべてのペイン、リスト、メニュー、ダイアログで使えます。
- 行を**ダブルクリック**すると、開く、または実行します。ローカルブランチ、tag、参照ピルをダブルクリックするとチェックアウトします。リポジトリの行をダブルクリックすると、そのリポジトリを開きます。
- 行を**右クリック**するとメニューが開きます。`.`、`Shift+F10`、またはメニューキーでも、選択中の行に対して同じメニューが開きます。
- **ホイール**は、ポインターの下のエリアをスクロールします。リストでは、表示だけが動きます。選択は、画面外にスクロールされても元の位置に残ります。選択を動かすのは、クリックまたはキーだけです。
- **Shift+ホイール**は横方向にスクロールします。対象は、折り返しがオフのときの diff、ファイルビュー、エディターです。
- ボタン、行、スクロールバーのつまみに**カーソルを合わせる**と、それが点灯します。多くのターミナルはマウスポインターの形を変えられないため、この点灯がクリックできることを示す唯一の手がかりになることがよくあります。ボタンやログのセルにポインターを置いたままにすると、ツールチップが表示されます。
- テキストフィールドの**外をクリック**すると、フィールドから抜けます。入力した内容は保たれます。Refs の絞り込みは、`Enter` と同じように入力した内容を適用します。ログの検索バーは、`Esc` と同じように閉じます。

## ウィンドウとダイアログを閉じる

枠のあるウィンドウやダイアログには、すべて枠の右上に `✕` があり、どこでも同じルールで閉じられます。

- **`✕` をクリック**すると閉じます。`Esc` も同じ動作で、ウィンドウより先に、いちばん内側のもの（開いているドロップダウン、テキストフィールド、確認）を閉じます。
- ダイアログ、ヘルプや情報のパネル、ポップアップは、**外側をクリック**しても閉じます。全画面のビュー（設定、Diff ビュー、ファイルビュー、各種エディター、レビュー、ボード）には外側がないため、外側のクリックでは閉じません。
- パネルの**内側**をクリックしても、閉じることはありません。
- 入力したテキストを含むフォーム（新しい Issue、プルリクエストやマージリクエスト）は、うっかりクリックして内容を失わないよう、外側のクリックを無視します。`✕` や `Esc` では、先に**変更を破棄しますか？**と確認され、**編集を続ける**を選ぶと戻ります。何も入力していないフォームと、1 行だけのダイアログは、すぐに閉じます。
- コマンドパレット、ピッカー（タブ、テーマ、言語）、小さなレビュー、ボード、merge、コンポーザーのダイアログ、確認プロンプトにも `✕` があります。コンテキストメニューとドロップダウンには `✕` がなく、`Esc` または外側のクリックで閉じます。

## 設定のリスト

設定のリスト（プロファイル、AI プロファイル、ワークフロー、開く場所、画像）では、マウスを次のように使えます。**サブタブ**（一般または一覧）を**クリック**すると、そのタブに切り替わります。`Alt+Left` / `Alt+Right` でも同じです。

- 行を**クリック**すると選択、**ダブルクリック**するとその行のフィールドへ移動、**ホイール**では選択せずにスクロールします。
- 行を**押したまま上下にドラッグ**すると並べ替えられます。落とす位置にバーが表示され、離すと確定、`Esc` でキャンセルします。キーボードでは `Alt+Up` / `Alt+Down` です。
- リストの下にある **`+ 追加`、`複製`、`削除`、`↑`、`↓`** をクリックします。キーは `Insert`、`Ctrl+D`、`Delete`、`Alt+Up` / `Alt+Down` です。[設定](settings.md#リスト)を参照してください。

## ポップアップ内のリスト

これらのルールは、絞り込みフィールドを持つポップアップ内のすべてのリストに当てはまります。コマンドパレット、そのピッカー（テーマ、言語、グラフの色）、タブピッカー、検索できるドロップダウン、Issue 参照の一覧、ヘルプです。

- 行を**クリック**すると選択します。
- 行を**ダブルクリック**すると、`Enter` と同じように、実行または選択します。
- **ホイール**でリストをスクロールします。選択は動きません。
- リストがポップアップより長いときは、右端に**スクロールバー**が表示されます。つまみをドラッグするか、トラックをクリックします。

絞り込みフィールドのない短いドロップダウンは、最初のクリックで行を選びます。コンテキストメニューは、最初のクリックで行を実行します。これらのリストのキーは、[キーバインド](keybindings.md#絞り込みできるポップアップ一覧)にあります。

## スクロールバー

スクロールできるエリアは、内容が収まりきらないとき、枠に細いスクロールバーを表示します。対象は、ログ、Refs のセクション、ファイル一覧、diff、ファイルビュー、エディター、ポップアップの一覧です。

- **つまみをドラッグ**してスクロールします。
- **トラックをクリック**すると、つまみがポインターの下に移動します。表示はその位置に比例してジャンプし、ボタンを押し続けるとドラッグし続けます。
- 端の矢印の上で**ボタンを押し続ける**と、スクロールし続けます。少し遅れて始まります。矢印から外れると一時停止します。
- スクロールバーが動かすのは表示だけです。選択は決して動きません。

diffとエディターでは、縦のスクロールバーがファイル全体も小さな印で示します。緑は追加された行、赤は削除された行、琥珀色は変更された行、`◆` はカーソルのある行、`▌` は選択したテキストが現れるそれ以外の場所です。merge エディターは、スクロールバー上に各競合の印を付けます。印をクリックすると、そこへ移動します。

## 失敗とアクティビティログ

- ステータスバーの**赤いエラーをクリック**すると、その項目でアクティビティログが開きます。項目の **コピー / 提案されたボタン**（やり直す、先に Pull、Stash してやり直す、連携を開く）を**クリック**します。
- ステータスバーの右端の **アクティビティ をクリック**すると、アクティビティログが開きます。タブをクリックして切り替え、レベルのチェックボックス（または **すべて** / **なし**）をクリックしてその行を表示または非表示にし、リポジトリのエントリをクリックして詳細を開き、アプリケーション タブの **ログを消去** をクリックします（先に確認が表示されます）。長い行は `Shift` + ホイールか横スクロールバーで横にスクロールできます。[アクティビティログ](troubleshooting.md#アクティビティログ)を参照してください。
- ステータスバー右のジョブ表示の **`[x]` をクリック**すると実行中のジョブを取り消し、**ラベルをクリック**するとジョブパネルが開きます。Home タブの右下にある **アクティビティ** ボタン（または `Ctrl+N Shift+G`）で、すべてのリポジトリを対象にアクティビティログが開きます（タブの下にある対象範囲ボックスのドロップダウンで、リポジトリまたはワークスペースを選べます）。

## サイズ変更

- Refs サイドバー、ログ、右ペインの間の**区切りをドラッグ**します。キーボードなら 1 段階ずつ動かせます。`Ctrl+N Left` / `Ctrl+N Right` は Refs | ログの区切り、`Ctrl+N Shift+Left` / `Ctrl+N Shift+Right` はログ | 右ペインの区切りを動かします（区切りは矢印の向きに動きます）。
  最小幅を超えてドラッグすると、そのペインが折りたたまれます。キーボードでの同等の操作は、`Ctrl+N Left` / `Ctrl+N Right`（Refs ペインとログの間の区切り）と `Ctrl+N Shift+Left` / `Ctrl+N Shift+Right`（ログと右ペインの間の区切り）で、どちらも 1 段階ずつ、区切りは矢印の向きに動きます。パレットには `ナビゲーション: Refs ペインを広げる`、`ナビゲーション: Refs ペインを狭める`、`ナビゲーション: Status ペインを広げる`、`ナビゲーション: Status ペインを狭める` として、`ナビゲーション: Refs ペインの折りたたみを切り替え` / `ナビゲーション: Status ペインの折りたたみを切り替え` です。
- Refs セクションの**下端をドラッグ**して高さを変えます。
- 右ペインの commit メッセージのブロックの**下端をドラッグ**します。
- 2 つのログヘッダーの**境界をドラッグ**して（既定では隙間を、ヘッダーからでも表のどこからでも。設定 > ログとグラフ > 列のサイズ変更）列幅を変えます（キーボードでは、`Shift+C` で列を選び、`]` / `[`）。
- 2 つのログヘッダーの**境界をダブルクリック**すると、その左の列が内容に合わせられます（キーボードでは、`Shift+C` で列を選び、`=`。`+` は全列を合わせます）。最後の列にはその列自身の最後のセルにグリップがあり、ドラッグするとその列の幅が変わり、差分は概要列が吸収します。
- **ログを横にスクロール**します（`scroll` 列レイアウト。設定 > ログとグラフ > 列のレイアウト、または選択ウィンドウの `横スクロール` チェックボックス）：表の上での水平ホイールまたは `Shift`+ホイール、下の枠線のバー（つまみのドラッグ、何もない軌道を押す、端の矢印をクリック）、または `Shift+Left` / `Shift+Right`。既定の `fit` レイアウトでは列がペインを埋めるため、スクロールするものはありません。
- ログのヘッダーを**ドラッグ**して列を移動します。名前のゴーストがポインターに付いてきて、元のヘッダーは暗くなり、移る位置にアクセント色のバーが出ます。列は離したときに移動し、`Esc` でキャンセルでき、運んでいる間、ポインターは開いた手の形になります（キーボードでは、`Shift+C` で列を選び、`<` / `>`）。

GitPoulpi はすべてのサイズを記憶します。[サイズは記憶されます](interface-tour.md#サイズは記憶されます)を参照してください。

## タイトルバー、タブ行、ツールバー

- タイトルバーの **🐙 をクリック**すると**GitPoulpi について**が開きます。このウィンドウでは、タコの瞳がポインターを追いかけます。ロゴをクリックすると次の色に回転し、右クリックすると色の一覧が開き、リンクをクリックするとそのリンクが開きます。
- タイトルバーの**開く場所 ▾ をクリック**すると、プログラムの一覧が開きます。[開く場所](open-in.md)を参照してください。
- タイトルバーの**バージョンをクリック**（`v1.0.0`、または `vX.Y.Z が利用可能`）すると、リリースノートのタブが開きます。
- タイトルバーの歯車のすぐ左にある**虫眼鏡と `全体検索` をクリック**すると、[全体検索](search.md)が開きます。
- タイトルバーの × のすぐ左にある**歯車をクリック**すると設定が開きます。
- タイトルバーの右端の **× をクリック**すると終了します。
- **タブをクリック**すると、そのタブに切り替わります。**その `x` をクリック**（選択中のタブとポインターの下のタブに表示されます）すると閉じます。タブを横に**ドラッグ**すると並べ替えられます。**タブを右クリック**するとタブメニューが開きます。
- **タブを中クリック**すると、その `x` と同じように閉じます。
- タブの両端の **`‹` または `›` をクリック**すると（タブが収まらないときに表示されます）、行が 1 タブ分スクロールします。ボタンを押し続けるとスクロールし続け、行の上でホイールを使うこともできます。タブを矢印の上にドラッグしても行がスクロールします。現在のタブが変わるたびに、行は自動でスクロールしてそのタブを表示します。
- 最後のタブの後ろの **`+` をクリック**すると、メニューが開きます：新しいタブ（`Alt+T`）と、それぞれのタブが閉じている間は Radar とワークスペース（`Alt+J`）。
- **家のアイコンをクリック**するとホームタブです。
- **Radar またはワークスペースのタブをクリック**すると、そのタブが開きます。その `x`、中クリック、`Ctrl+W` で閉じます。**ワークスペースのチップをクリック**（`Alt+W`）すると、ワークスペースを切り替えます。
- **終了して cd をクリック**（`gp` シェルラッパー経由で GitPoulpi を起動したときにタブの右側に表示されます）すると、終了してシェルをアクティブなタブのフォルダーに残します。[アクティブなタブのフォルダーに追従](following-the-tab-folder.md)を参照してください。
- **ツールバーのボタンをクリック**すると実行します。Pull、Push、LFS の横の **`▾` をクリック**すると、その一覧が開きます。**`⋯` をクリック**すると、収まらなかったボタンが表示されます。
- ツールバーの右端の**プロファイルのコンボボックスをクリック**すると、このリポジトリの commit の作成者 ID を選べます。

## ホームタブ

- 行を**クリック**すると選択します。**ダブルクリック**するとリポジトリを開きます。
- **星をクリック**すると、お気に入りに追加/削除します。
- 行の**開く、切替、閉じる、削除をクリック**します。**`⋮`** をクリックすると、その行のメニューが開きます。行を**右クリック**しても同じメニューが開きます。
- **セクションのタイトルをクリック**すると、そのセクションを折りたたみます。
- 上部の**参照、クローン、初期化、すべて折りたたむ、すべて展開をクリック**します。セクションのタイトルでは、**すべてのタブを閉じる**や**すべて削除**をクリックします。

**参照**のフォルダーピッカーでは、場所やフォルダーをクリックするとそこへ移動し、フォルダーをダブルクリックすると開き、パスのフィールドをクリックするとパスを入力できます。**兄弟フォルダーを表示**（`Alt+S`、記憶されます）にチェックを入れると、左のツリーに、開いている各階層のほかのフォルダーも並びます。開いているパス上のフォルダーには `▾`、そのほかには `▸` が付き、クリックするとそこへ移動します。**クローン**と**初期化**では、フィールドをクリックして入力し、ボタンやチェックボックスをクリックして使います。

## Refs サイドバー

- 行を**クリック**すると選択します。ローカルブランチまたは tag を**ダブルクリック**するとチェックアウトします。worktree またはサブモジュールを**ダブルクリック**すると、タブで開きます。WORKTREE 見出しの **+** で worktree を作成します。worktree を右クリックすると、新しいタブで開く、開く場所、merge、削除が使えます（[worktree](worktrees.md)）。
- 行に**カーソルを合わせる**と、左にアイコンが表示されます。それを**クリック**すると、ログでその参照を非表示にする、または再び表示します。**ソロ表示**がオンのあいだは、同じ場所でその参照をソロ表示にします。フォルダーの行では、アイコンがそのフォルダー内のすべての参照に作用します。
- サイドバーのタイトルの**ソロ解除**または**すべて表示**を**クリック**すると、すべてのソロ表示、またはすべての非表示の参照を解除します。
- 行を**右クリック**するとメニューが開きます。チェックアウト、merge、早送り、rebase、worktree の作成、名前の変更、削除、非表示、ソロ表示など。リモート自体の行には、**Fetch**、**編集**、**削除**などのリモート操作があります。stash には **Pop（復元して削除）**、**Apply（stashを残す）**、**Drop** があります。グレーの行は、実行できない理由を表示します。
- リモートのタイトルの **`+` をクリック**すると、リモートを追加します。
- **フォルダーの行をクリック**すると、折りたたむ/展開します。

### Pull request と Issue

| ジェスチャー | 動作 |
|---|---|
| 行をクリック | 選択します。 |
| 行をダブルクリック | ブラウザーで開きます。 |
| 行を右クリック | その行のメニュー：開く、URL または番号のコピー、元のブランチのチェックアウト、Issue からのブランチ作成。 |
| セクションのタイトルの `+` をクリック | **Pull Request を作成**フォーム、または**新規 Issue**フォームを開きます。 |
| 絞り込みの行（`オープン ▾`）をクリック | 一覧に表示するリクエストや Issue を選びます。 |
| グループのタイトルをクリック | グループを折りたたむ/展開します。 |
| プロバイダーまたはリポジトリの行（ISSUES）をクリック | Issue の取得元を選びます。**なし（このリポジトリのリンクを解除）**で取り除きます。 |
| クエリの行（ISSUES）をクリック | JQL または WIQL のクエリ（Jira、Azure DevOps）を入力するか、Trello のリストを選びます。 |
| ツールバーのチップ（`GH #12`、`GL !53`、...）をクリック | pull request をブラウザーで開きます。右クリックすると、**ブラウザーで開く**、**URL をコピー**、**更新**、**プロファイルを切り替え**が使えます。 |
| 薄い `+ PR` チップをクリック | push 済みのブランチの pull request を開始します。 |

[ホスティングと Issue トラッカー](hosting-integration.md)を参照してください。

## ログ

- commit を**クリック**すると選択します。その詳細は右ペインに表示されます。
- **Ctrl+クリック**で commit を選択に加える、または外します。**Shift+クリック**で範囲を選択します（Shift+クリックをターミナル自身のテキスト選択に使う kitty や Windows Terminal などでは **Alt+クリック**）。選択した commit を右クリックすると、まとめて cherry-pick できます。選択には WIP 行と stash も含められます。2 行以上を選択すると右ペインが比較に変わります（[commit を比較する](log-and-history.md#commit-を比較する)を参照）。
- 比較ペインの**カードをクリック**すると、ログのカーソルがその行に移ります。**入れ替え をクリック**すると、比較元と比較先が入れ替わります。行の単純なクリックで比較を抜けます。
- **WIP 行をクリック**すると作業中の変更になります。**`// WIP` の文字をクリック**すると、そこに commit の概要を入力できます。
- セルに**カーソルを合わせる**と全文が表示されます。メッセージ、作成者とメールアドレス、完全な日付、完全なハッシュです。
- **`+N` バッジにカーソルを合わせる**と、その commit のほかの参照が表示されます。ポップアップの中へ移動して、参照をクリックできます。ポップアップ内の参照をダブルクリックするとチェックアウトします。
- **参照ピルをダブルクリック**するとチェックアウトします。
- **commitを右クリック**すると commit メニューが開きます。その commit 上の参照ごとにサブメニューが 1 つあります。
- **参照ピルを右クリック**すると、その参照の操作と commit の操作を 1 つにまとめたメニューが開きます。
- **ヘッダーを右クリック**すると、列の表示/非表示を選べます。タイトルに ✕ のあるチェックリスト（`[x]` / `[ ]`）が開き、行をクリックするか、矢印キーと `Space` / `Enter` で切り替え、✕、`Esc`、または外側のクリックで閉じます（パレット：`表示: Log: 表示する列を選択`）。チェックボックスの下には、`<列>を内容に合わせる`（右クリックした列）、`全列を内容に合わせる`、`列の幅をリセット` があります。右クリックのキーボード版：`Shift+C` で列を選び、`.`（または `Shift+F10`）でその列に同じメニューが開きます。
- **Radar の列**も同じように働きます：リポジトリ、`#`、作成者、経過の列の後ろの区切りをドラッグするとサイズが変わり、**ダブルクリック**すると列が最も幅の広い項目に合わせられ（`C` で列を選び、`=`。`+` は全列を合わせます）、**列のタイトルを右クリック**（または `C` のあとに `.`）すると `<列>を内容に合わせる` と `全列を内容に合わせる` が出ます。
- 検索バーの **`↑`、`↓`、`✕` をクリック**すると、前/次の一致へ移動する、またはバーを閉じます。
- 右ペインの commit メッセージ内の **`#12`、`ABC-12`、`AB#12` をクリック**すると、その Issue または pull request がブラウザーで開きます。

### 左ペインのセクション

**フォルダー**（`a/b/c` という名前のブランチと tag、ツリー表示の右ペインのファイル）は、まとめて折りたたんだり展開したりできます。フォルダーのあるセクションの**見出しか空いている部分を右クリック**すると **すべて展開** / **すべて折りたたむ**（と、下のチェックリストへ進む **セクションの表示/非表示...**）が、**フォルダーの行を右クリック**すると **すべてのサブフォルダーを展開** / **すべてのサブフォルダーを折りたたむ**（そのフォルダーとその下のすべて）が使えます。キーは、Refs ペイン、Unstaged と Staged の一覧、commit の変更ファイルのどこでも同じです。`=` ですべて展開、`-` ですべて折りたたみ、`*`（または `Shift+Right`）でカーソル位置のフォルダーとその下のすべてを展開、`_`（または `Shift+Left`）で折りたたみます。パレット：*Refs: すべてのフォルダーを展開*、*Refs: すべてのフォルダーを折りたたむ*、*Refs: 選択中のフォルダーとそのサブフォルダーを展開*、*Refs: 選択中のフォルダーとそのサブフォルダーを折りたたむ*、そしてフォーカス中のファイル一覧向けの 4 つの *ファイル:* の同等コマンド。名前のフィルター（Refs のフィルター、commit の *ファイルを絞り込み*）が有効な間は、一致を含むすべてのフォルダーが、折りたたんでいたかどうかにかかわらず開いて表示されます。あなた自身の折りたたみは変更も保存もされず、フィルターを解除すると元に戻ります。フィルター中に行った折りたたみは、表示中のものに作用し、フィルターとともに忘れられます。

**セクションの見出し**（フォルダーのないセクション、または左ペインの空いている部分）を**右クリック**すると、セクションのチェックリストが開きます：ローカル、リモート、ワークツリー、Stashes、Tags、Pull requests、Issues、サブモジュール。クリックするとセクションのチェックが外れたり付いたりし、メニューは開いたままです。非表示のセクションは描画されず、キーボードでも飛ばされます。最後に残った表示中のセクションはチェックを外せません。この選択はリポジトリごとに保たれ、再起動しても残ります。独自の選択がないリポジトリは既定（グローバルの `ui.sidebar_sections_hidden`）に従います。*すべてのリポジトリに使う*は現在の選択を既定にし、*既定の状態に戻す*はこのリポジトリ独自の選択を破棄します（パレット：*サイドバー: このセクション設定をすべてのリポジトリに使う*）。パレット：*サイドバー: セクションの表示/非表示...*、セクションごとの *表示/非表示* コマンド、*セクションを既定の状態に戻す*。

### 参照のドラッグ

Refs サイドバーのブランチ、またはログの参照ピルを押したまま、別のブランチの上へドラッグします。何を運んでいるかがステータスバーに表示されます。ドロップを受け付けられる対象が点灯します。離すとメニューが開きます。`Esc` でドラッグをキャンセルします。

| ドラッグ | メニュー |
|---|---|
| ローカルブランチ X をローカルブランチ Y へ | **X を Y に merge**、**X を Y に rebase**、**X を Y にインタラクティブに rebase...**、**Y を X に早送り** |
| ローカルブランチをリモートブランチへ | そのリモートへ **X を push** |
| リモートブランチをローカルブランチ Y へ | **Merge**、**Y をそれに rebase**、**Y をそれに早送り**、そして Y のアップストリームの場合は **Pull** |

操作がチェックアウトされていないブランチを変更する場合、GitPoulpi はまずそのブランチをチェックアウトします。git がチェックアウトを拒否した場合は、何も変わりません。tag はドラッグできず、ドロップも受け付けません。

キーボード：「マークしてからドロップ」は、どの参照の組み合わせでもドラッグと同じことをします。Refs ペインでブランチの上で `m` を押します（パレット：`Refs: ドロップ元としてマーク`）。その参照には `◆` が付いて下線が引かれ、ログ上のピルにも同じ表示が出て、ステータスバーが移動先を案内します。ほかの参照を（どのセクションでも）選んで `Shift+M` を押すと（パレット：`Refs: マークした参照をここにドロップ...`）、ドラッグで開くのと同じメニューが現れ、その行はドラッグの後とまったく同じように実行されます。メニューが開くとマークは使い切られます。それ以前なら、`Esc`、またはマークした参照の上でもう一度 `m` を押すと解除されます。パレットコマンド `Refs: 選択中の参照をチェックアウト中のブランチにドロップ...` は、選択中の参照と現在のブランチに対してメニューを開きます。

## 右ペイン

### 作業中の変更

- ファイルを**クリック**すると diff が開きます。**同じファイルをもう一度クリック**するとログに戻ります。そのファイルが未保存の変更付きでエディターに開かれている場合は、GitPoulpi が先に確認します。
- 行に**カーソルを合わせる**と、**ファイルをステージ**または**ファイルをステージ解除**ボタンが表示されます。フォルダーの行には**フォルダーをステージ**または**フォルダーをステージ解除**があります。
- セクションのタイトルの**すべての変更をステージ**または**すべてステージ解除**を**クリック**します。
- **セクションのタイトルをクリック**（`未ステージのファイル`、`ステージ済みのファイル`）すると、折りたたみます。
- **パスまたはツリーをクリック**すると、フラットな一覧かフォルダー表示かを選べます。**すべて折りたたむ**または**すべて展開**を**クリック**すると、すべてのフォルダーを折りたたむ/展開します。
- タイトルの左の **`✖` をクリック**すると、すべての変更を破棄します（先に確認します）。右の **`✦` をクリック**すると、AI で変更を説明します。
- **ファイルを右クリック**するとメニューが開きます。ステージ、破棄、無視、LFS、ファイルの stash、履歴、Blame、外部プログラムで開く、パスのコピー、パッチの作成、編集、削除。競合したファイルでは、**...で解決**の行が最初に並びます。
- **フォルダーの行を右クリック**するとフォルダーのメニューが開きます。ステージ、破棄、無視、stash、パッチの作成、フォルダーを開く、その中にファイルを作成。
- 未ステージのファイルの**空白部分を右クリック**すると、**ファイルを作成**が使えます。
- **無視**、**バイナリとして扱う**、**テキストとして扱う**（ファイルとフォルダーのメニュー）は、まずルールを書き込める `.gitignore` または `.gitattributes` の一覧を開きます。行をクリックして `Enter` を押す（または矢印キーを使う）と書き込まれ、`Esc` または外側のクリックで何も書かずにキャンセルします。
- ファイルまたはフォルダー行を **Ctrl+クリック**で選択に追加／除外、**Shift+クリック**（**Alt+クリック**）で範囲選択。commit の変更ファイルとすべてのファイルを表示でも同じです。通常のクリックでやり直します。**選択された行を右クリック**すると、選択したすべてのファイルのメニューが開きます。
- **一覧の空白部分を右クリック**すると **リポジトリのフォルダーを開く** も表示されます。未ステージの一覧では **すべてステージ** と **すべての変更を破棄...**、ステージ済みの一覧では **すべてステージ解除** が加わります。
- **変換**（ファイル、フォルダー、選択のメニュー）は、ディスク上のファイルのエンコーディング、改行コード、インデントを書き換えます。`Ctrl+Z` 1 回でバッチ全体を取り消せます。

### commit フォーム

- 概要または説明を**クリック**すると入力できます。
- **直前の commit を修正（Amend）をクリック**すると、amend のオン/オフを切り替えます。
- **commit ボタンをクリック**（`N ファイルの変更を commit`）すると commit します。ボタンがグレーのときにクリックすると、理由が表示されます（たとえば *commit する変更をステージしてください*）。
- 概要の右にある **`✦` をクリック**すると、AI でメッセージを書きます。
- 概要の末尾にある **`#▾` をクリック**すると、Issue の一覧が開きます。1 つをクリックすると、その参照が挿入されます。
- **AI で commit を構成をクリック**すると、commit コンポーザーが開きます。

### commit の詳細

- 変更されたファイルを**クリック**すると diff が開きます。**もう一度クリック**するとログに戻ります。
- メッセージの下端を**ドラッグ**するとサイズを変えられます。メッセージの上でホイールを回すと、長い説明をスクロールできます。
- 概要、説明、作成者のブロックを**右クリック**すると、*概要を修正...*、*説明を修正...*、*作成者を修正...* が使えます。どれか（または作成日時）を**ダブルクリック**すると、その欄にキャレットを置いた完全な修正ダイアログが開きます。キーボードでは `Ctrl+G Shift+E`（すべての欄）と `Ctrl+G Shift+A`（作成者）です。概要と説明はパレットにあります。
- 変更ファイル、フォルダー行、一覧の空白部分、または選択を**右クリック**するとメニューが開きます（開く、履歴、blame、プログラムで開く、パスのコピー、無視、バイナリ／テキストとして扱う、変換、commit から復元、削除）。**Ctrl+クリック**と **Shift+クリック**で複数のファイルを選択できます。

[ステージと commit](staging-and-committing.md)を参照してください。

## diff とファイルビュー

- diff の上のバーの**ボタンをクリック**します。ファイルビュー、Diff、Blame、`ファイル │ すべて` の列の切り替え、編集、`↑` `↓`、インライン、分割、ハンク、WS、折返、マップ、文字コード。オンのボタンは強調表示されます。`ファイル` または `すべて` をクリックすると、その一覧が Commit列に表示されます。すでに選択されている部分をクリックすると、列が隠れます（[Commit列](interface-tour.md#commit列)を参照）。
- タイトルの **`✕` をクリック**すると、ファイルを閉じます。
- ハンクに**カーソルを合わせる**と、**ハンクをステージ**または**ハンクをステージ解除**と、**ハンクを破棄**が表示されます。
- 変更された行に**カーソルを合わせる**と、行の右端に、その行専用の **+ Stage**、**− Unstage**、**✖ Discard** ボタンが表示されます。
- **行を右クリック**するとハンクのメニューが開きます。ハンクまたは選択した行のステージ、ステージ解除、破棄、ファイル履歴、Blame、コピー。
- **ミニマップをクリック**すると、その行へ表示を移動します。ボタンを押したまま動かすとスクロールします。

破棄は必ず先に確認します。破棄で未追跡ファイルを削除したとき、完全に空になったフォルダーも一緒に削除されます（追跡済み、無視された、または隠しファイルがまだ入っているフォルダーや、もともと空だったフォルダーは残ります）。元に戻すと、ファイルがフォルダーごと戻ります。

### Blame とファイル履歴

- **Blame。** 注釈の上にポインターを置くとハンクのカードが出ます。クリックでハンクを選択し、右クリックでそのメニューを開きます。注釈列の境界をドラッグして幅を変えます（保存されます）。ミニマップ上をクリックまたはドラッグしてスクロールします。
- **ファイル履歴。** クリックで commit を選択、`Shift+クリック` で比較する範囲を選択、ダブルクリックでログに commit を表示、右クリックで行のメニュー、一覧と diff の間の境界をドラッグして幅を変更、一覧の ✕ で一覧を隠します（`›` のストリップをクリックすると戻ります）。バーの `ファイルビュー` / `Diff` / `Blame` をクリックして右側の表示内容を切り替え、`ファイル │ すべて` の切り替えで列の一覧を選びます。ホイールはポインターの下の半分をスクロールします。どれにもキーボードでの操作があります（[Blame](log-and-history.md#blame)、[ファイル履歴](log-and-history.md#ファイル履歴)）。

### Commit列（すべての一覧）

- **行にポインターを置く**と、ログと同じツールチップが出ます（ポインターの下の部分に応じて、メッセージ全体、作成者の名前とメールアドレス、完全な日付）。
- **行を右クリック**するとメニューが開きます：ログで表示、その commit でのファイルの diff、その commit 時点のファイル、その Blame、続いてその commit に対するログのメニュー。キーボードではメニューキーで同じことができます。
- **ヘッダーの境界をドラッグ**（`ui.column_resize`：既定では 2 つの欄の間の 1 セル幅の区切りで、ヘッダーでは薄い `│` で示され、ポインターが乗っている間は列に沿ってアクセント色の線が描かれ、線上のどこからでもドラッグしてサイズを変えられます。`header` では次の名前の先頭の文字で、ポインターが乗っている間は光ります）すると、その左にある欄（レーン、メッセージ、作成者、日付、Ref、変更、SHA）の幅を変えられます。最後の欄の直後のセルが、最後の欄の境界です。
- **ヘッダーの名前をドラッグ**して別の名前の上へ落とすと、その欄をそこへ移動できます。ログのヘッダーと同じゴースト、暗くなる元の位置、アクセント色のバーが出て、欄は離したときに移動します（`Esc` でキャンセル。キーボードでは `Tab` の後に `<` / `>` で、1 つずつ同じ操作ができます）。
- **ヘッダーの境界をダブルクリック**すると、Log の境界と同じように、その左の欄が内容に合わせられます：最も幅の広い行を全体表示できる幅で、列の幅を超えることはありません（キーボードでは、行をクリックするか `Ctrl+N` で列にキーを渡し、`Tab` で欄を選び、`=`。`+` は全欄を合わせます。パレットには `欄を内容に合わせる` と `全欄を内容に合わせる` があります）。概要には、ほかの欄が使い残した分が割り当てられます。
- **ヘッダーを右クリック**すると、表示する欄を選べます（Ref、グラフ、作成者、日付、変更、SHA。概要は常に表示されます）。チェックリストのタイトルには ✕ があります。その下に `<欄>を内容に合わせる`（右クリックした欄）と `全列を内容に合わせる` があります。パレットには `列を選択`（`Tab` で選んだ欄にキーボードからメニューを開きます）と、欄ごとの切り替えがあります。
- 行が列より広いときは、**Shift+ホイール**または横ホイールで行を横にスクロールします。
- 列の**右の枠線をドラッグ**すると幅を変えられます。**`›` のストリップをクリック**する（または列の ✕、バーの `ファイル │ すべて` の切り替えの**選択中の部分をクリック**する）と、列を戻したり隠したりします。

### テキストの選択とコピー

diff、ファイルビュー、Blame、履歴のテキストを選択してコピーできます。

- **押したままドラッグ**してテキストを選択します。スクロールしても、選択は同じテキストに留まります。
- **ダブルクリック**すると単語を選択します。
- **単なるクリック**ではテキストを選択しません。カーソルを動かす、または行を選択し、テキストの選択を解除します。
- **`y` または `Ctrl+C`** で選択範囲をコピーします。選択がないときは、現在の行をコピーします。
- diff で**右クリック**すると、**選択範囲をコピー**、**行をコピー**、**ハンクをコピー**が使えます。

GitPoulpi がコピーするのは、ファイルのテキストだけです。行番号、`+` と `-` の印、ハンクヘッダー、Blame の列はコピーされません。分割表示では、選択はドラッグを始めた側に留まります。

diff では、ドラッグすると、`v` のように、通過した行も選択されます。そこで `Enter` を押すと、それらの行がステージされます。`Esc` は、まずテキストの選択を、次に行の選択を解除し、その次に diff を閉じます。

テキストを選択すると、diffとエディターのほかの場所に現れる同じテキストにも色が付きます。

## テキストフィールド

フィルター、検索バー、パレット、概要と説明、ダイアログのフィールド、設定の値など、すべてのテキストフィールドに当てはまります。

- **クリック**するとそこにキャレットを置きます。
- **押したままドラッグ**してテキストを選択します。
- **ダブルクリック**すると単語を選択します。
- 入力すると選択範囲を置き換えます。`Backspace` または `Delete` で削除します。

テキストフィールドのキーは[キーバインド](keybindings.md)にあります。

## エディター

- **クリック**するとキャレットを置きます。**Shift+クリック**で選択を広げます。
- **ドラッグ**して選択します。上端または下端を越えてドラッグするとスクロールします。
- **ダブルクリック**すると単語を選択します。
- **ホイール**は、キャレットを動かさずにスクロールします。
- バーの**保存、元に戻す、やり直す、検索をクリック**します。検索モードでは、**`↑`** と **`↓`** で前/次の一致へ移動します。
- **`✕` をクリック**すると閉じます。未保存の変更があるときは、GitPoulpi が先に確認します。

## ダイアログの移動とサイズ変更

ダイアログは移動でき、大きいウィンドウはサイズ変更もできます。

- **タイトルバーをドラッグ**するとダイアログを移動します（閉じる十字はクリックのままです）。コマンドパレットとピッカーには独立したタイトルバーがないので、上の枠をドラッグします。
- **左・右・下の枠**、または下の角（`◢` のつまみ）を**ドラッグ**するとウィンドウのサイズが変わります。ダイアログは画面内に収まり、最小サイズより小さくなりません（元に戻す履歴は 60 x 16、ほかはそれより小さい値）。サイズを変えたウィンドウは広がった分を使い、テキスト領域と一覧が大きくなり、テキストは新しい幅で折り返されます。
- ポインターがダイアログから出てもドラッグは続き、外でボタンを離しても閉じません。
- 元に戻す履歴の Reflog / 失われた作業ビューの内側にある**区切りをドラッグ**できます。ダブルクリックするとリセットされます。
- キーボードでは `Ctrl+N` のあとに `m`（矢印で移動、`Shift`+矢印でサイズ変更、`0` でリセット、`Enter` か `Esc` で終了）、区切りは `Alt`+矢印です。パレットには `ダイアログ: 移動 / サイズ変更` と `ダイアログ: 位置とサイズをリセット` があります。これらは一番手前のダイアログに作用します。`Ctrl+N` はどの画面でも同じように働きます。手前のウィンドウ、ダイアログ、ポップアップのコントロール（フィールド、一覧、タブ、ボタン、閉じる ✕）にバッジが表示され、続けて押したキーでそのコントロールが押され、`m` で調整モードが始まり、`Esc` で取り消されます。ステータス行には `<badge>`、`m=arrange`、`Esc` が表示されます。これはコマンドパレット、ピッカー、ワークスペース検索、ヘルプオーバーレイでも同じで、これらでは `Ctrl+N` で一覧を下へ移動することはなくなりました。`Alt+G`（`palette.arrange`）は、プレフィックスなしで手前のダイアログやポップアップを調整できる、すべてのダイアログとポップアップで使える追加の方法です。
- **1 つの設定**（`ui.dialog_geometry`、設定 > 外観 > レイアウト）がすべてのダイアログに効きます。各ダイアログが、このセッション中、次回の起動まで（ディスクに保存）、または保持しない、のいずれかでそれぞれの位置とサイズを記憶します。

| ダイアログ | 移動 | サイズ変更 |
|---|---|---|
| 元に戻す履歴 / Reflog / 失われた作業、アクティビティログ、ジョブパネル、フォルダーピッカー | 可 | 可 |
| コマンドパレット、タブ / テーマ / 言語のピッカー、ワークスペース検索 | 可 | 可（リストは高さに、行は幅に合わせて広がります） |
| Clone（リポジトリ一覧）、プルリクエストと新しい Issue（説明）、「送信する内容」（ペイン）、Mermaid（プレビュー）、レビューのオプション（フィールド、幅のみ） | 可 | 可 |
| 設定の長文エディター（テンプレート、フック、AI プロンプト）、ワークスペースフォームの AI ボックス | 可 | 可（テキスト領域） |
| 履歴の書き換え：2 つの AI ヘルパーダイアログ | 可 | 可（説明、送信ペイン） |
| バージョン情報、アップデートパネル、セキュリティチェック、予測される競合、「AI の上限を超えています」、tag の削除、機密ファイル | 可 | 不可（サイズはテキストに合わせます） |
| Init、Worktree、スパースチェックアウト、Flow ダイアログ、Issue フローのダイアログ、commit メッセージ（reword）フォーム、ワークスペースフォーム、ラベル / マイルストーンのピッカー | 可 | 不可 |
| 確認（すべての「よろしいですか？」） | 可 | 不可 |
| レビューとボードのダイアログ：小さなダイアログ（コメント、完了、選択、列） | 可 | 不可 |
| キーバインディングページのポップアップ（リセットの確認、キーの取得）、AI の回答ポップアップ | 可 | 不可 |
| 設定：リポジトリ認証の結果と確認 | 可 | 不可 |
| 履歴の書き換え：purge、ID、質問のダイアログ | 可 | 不可 |
| commit コンポーザーのファイル移動ポップアップ、merge の通知 | 可 | 不可 |

移動できないもの：全画面のページ（設定、ヘルプ、レビューとボードのページ。すでにウィンドウ全体に広がっています）、コンテキストメニューとドロップダウン（開いた要素に付いています）、ツールチップ、ページ内の小さなポップアップ（リモートのフォーム、commit 分割エディター）。

ポインターの形は、タイトルバーの上では移動、枠と角の上ではサイズ変更になります（`OSC 22` に対応するターミナル）。

## マウスポインターの形

一部のターミナルでは、GitPoulpi がマウスポインターの形を変えられます。区切りの上、Log・Radar・commit 列の列の境界の上（ドラッグ中も）ではリサイズ用のポインター、クリックできる項目の上では手の形です。kitty、foot、Ghostty、mintty、およびアップストリームの PR #8092 を含む WezTerm のビルドで動作します（シーケンスは `OSC 22`）。形が変わったときだけ送られ、tmux の中ではパススルー用に包んだときだけ送られ（`allow-passthrough on`。kitty と foot では表示され、Ghostty では表示されません）、screen、zellij、herdr の中では送られません。GitPoulpi の終了時には、既定のポインターに戻ります。ほかのターミナル（Rio、Alacritty、Tabby、iTerm2、Terminal.app、Windows Terminal、xterm）では、ポインターは変わりません。[ターミナルの選び方](terminals.md#マウスポインターの形osc-22)を参照してください。ポインターの下の区切りやボタンは、どのターミナルでも点灯します。

同じ種類の部品には、アプリ全体で同じポインターが使われます。

- **ボタンは本物のボタン**です。設定（連携：編集、切断、削除、参照、消去、指示エディターのスニペットボタンなど）でもダイアログでも同じです：余白のあるラベルが塗りつぶされた背景に載り、ポインターが乗ると明るくなり、無効のときは暗くなり、`[ ]` で囲んだ文字にはなりません。残っている角括弧はチェックボックスのマーク `[x]` / `[ ]` だけで、これはチェックボックスなので、ほかのコントロールと同じように手の形になります。
- **指差しの手**はコントロールの上です。ボタン、チェックボックスとトグル、コンボボックス（設定、Issue とプルリクエストのペイン、Radar、ダイアログ）、タブとその ×、`+` ボタン、リンクと参照（`#12`、`!45`）、展開矢印付きのグループとフォルダーの見出し、ref のピル、スクロールバー、ステータスバーのアクティビティ、ジョブ、バージョンのボタン。行の中のチェックボックスやボタンも手のままです。
- **矢印**は行の上です。ポインターが乗ると行は全体として光り（どの一覧でも同じ光り方）、行そのものはコントロールではありません。Refs、Worktrees、Stashes、Submodules の各ペインの行、ログと commit 列（手になるのは ref のピルだけ）、diff の行、変更されたファイル、プルリクエスト、Issue、Radar の項目、ダイアログやパネルの一覧の行（クローン、フォルダー選択、ワークスペース、ボードのカード、ジョブパネル、担当者・ラベル・マイルストーンの選択、rebase のステップ、レビューのファイルと commit、メニューとコンボボックスの選択肢）。
- **テキストカーソル（I ビーム）**は入力ボックスの上で、ボックス全体にわたります。検索ボックス（グローバル検索、設定、コマンドパレット、Home）、フィルター（Refs、ファイル、Radar、アクティビティログ、Issue ペインの検索）、設定のテキスト・数値・エリアの行（編集中も）、ダイアログのフィールド、レビューのコメントボックス、commit コンポーザー、ファイルエディターのテキスト、マージエディターの編集できる結果（読み取り専用のペインは矢印のままです）。commit の詳細では、メッセージと説明が編集できるので I ビームが出て、ブロック全体が薄く光ります。
- **commit の詳細**では、情報の行がコントロールです。`commit: <id>` をクリックすると短い ID をコピーし、作成者または日付の行をダブルクリックすると修正できます（手の形と薄い印が付きます）。統計の行は情報を示すだけで、矢印のままです。

リサイズ用のポインターは区切りと列の境界の上に留まり、開いた手は ref を運んでいる間だけ表示されます。

## クリップボードへのコピー

コピー操作は、GitPoulpi が動いているマシンのシステムのクリップボードにテキストを入れ、ターミナルが対応していると分かっている場合は、ターミナルにも送ります（OSC 52）。SSH 経由やディスプレイがない環境では OSC 52 だけが送られます。お使いのターミナルが対応していない場合（クリップボードの許可をオンにするまでの iTerm2、Terminal.app、GNU screen）は何もコピーされず、ステータス行にはテキストをターミナルに送っただけだと表示されます。[ターミナルの選び方](terminals.md#クリップボードコピー操作)を参照してください。
