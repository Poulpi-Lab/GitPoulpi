# 워크스페이스

**워크스페이스**는 이름이 붙은 저장소 묶음입니다. 함께 작업하는 저장소(프런트엔드,
그 API, 문서)를 한데 모읍니다. 그중 어떤 저장소가 탭으로 열려 있는지 기억하고,
**기본 commit 프로필**을 둘 수 있어서 직접 전환하지 않아도 그 저장소들의 commit이
알맞은 신원을 사용합니다. 저장소는 여러 워크스페이스에 속할 수 있고, 어디에도 속하지
않아도 괜찮습니다. "워크스페이스 없음"은 지금까지와 같은 평범한 탭 목록입니다.

워크스페이스는 `config.toml` 옆의 `workspaces.toml`에 저장되며 모든 세션, 창, CLI,
MCP(`gitpoulpi workspace ...`, [CLI 참조](cli-reference.md) 참고)가 공유합니다. 창이 열려 있는 동안 셸이나
`gitpoulpi workspace ...`로 추가, 이름 변경 또는 제거한 워크스페이스는 키를 누르지 않아도 1초쯤 안에 저절로 나타납니다(워크스페이스
탭, 탭 표시줄의 칩과 그 목록). 워크스페이스를 닫거나 삭제해도 디스크의 저장소는 절대 건드리지 않습니다.
워크스페이스 편집은 즐겨찾기나 프로필처럼 설정이므로 [실행 취소와 다시 실행](undo-redo.md)에
포함되지 않으며, 삭제는 먼저 확인을 묻습니다.

## 워크스페이스 칩

워크스페이스가 하나 생기면 탭 표시줄의 `⌂` 바로 뒤에 칩이 나타납니다. 색 점과
활성 워크스페이스의 이름, 또는 "워크스페이스 없음"(흐리게)입니다. 표시줄이 좁으면
점만 남고, 아주 좁으면 사라집니다.

![탭 표시줄 위의 워크스페이스 드롭다운: 워크스페이스 없음, Orbit(체크됨), Side projects, Archive, 워크스페이스 관리 항목, 그리고 도구 모음의 Orbit 칩과 프로필 "Work - 워크스페이스 Orbit에서"](../images/workspace-switch.png)

- **칩을 클릭**하거나 `Alt+W`를 누르거나 팔레트에서 `워크스페이스: 전환...`을
  실행하면 드롭다운이 열립니다. 내 워크스페이스, "워크스페이스 없음", "워크스페이스
  관리..."(워크스페이스 탭을 엽니다)가 나옵니다.
- **전환하면 탭이 바뀝니다.** 떠나는 워크스페이스에서 열려 있던 탭은 보관되고, 대상
  워크스페이스의 탭이 돌아옵니다(처음에는 존재하는 저장소들). 다시 돌아오면 모든 것이
  떠난 그대로입니다. 탭을 전환할 때처럼 창만 다시 시작하며 데몬은 그대로입니다.
- **워크스페이스는 기억됩니다.** 다음에 실행하면 그 워크스페이스로 돌아옵니다.
- 워크스페이스의 **마지막 탭을 닫으면** 워크스페이스는 활성 상태로 남고 홈 탭이
  표시됩니다.
- **워크스페이스가 활성일 때 `+`(새 탭)**는 고른 저장소를 탭 목록에 추가할 뿐 아무것도
  묻지 않습니다. 워크스페이스 자체에 넣으려면 탭의 오른쪽 클릭 메뉴에서 "워크스페이스에
  추가"(또는 `워크스페이스: 탭을 워크스페이스에 추가`)를 사용하세요. "워크스페이스에서
  제거"는 탭을 연 채로 워크스페이스에서만 뺍니다.

워크스페이스가 아직 없으면 칩도 없습니다. 먼저 워크스페이스 탭이나 팔레트에서 하나 만드세요.

## 워크스페이스 탭

`+` 메뉴, `Alt+J` 또는 팔레트의 `워크스페이스: 관리...`로 엽니다. `x`(또는 `Ctrl+W`)로 닫으며, 닫을 때까지 다시 시작해도 열려 있습니다. 각 워크스페이스는 색 점, 이름, 포함한 저장소 수(와
누락된 수), 기본 프로필이 표시되는 한 행이며, 창이 그 워크스페이스에 있으면 "활성"이
붙습니다. `Right`, `Space` 또는 클릭으로 펼치면 그 저장소들이 보입니다.

![워크스페이스 탭: 저장소 두 개로 펼쳐진 Orbit, Side projects, 그리고 "1개 누락"으로 표시된 Archive](../images/workspaces.png)

| 워크스페이스별 | 키 | |
|---|---|---|
| 열기 | `Enter` | 활성으로 만들고 그 탭을 엽니다. |
| 편집... | `e` | 아래의 양식. |
| 삭제... | `x` | 먼저 묻습니다. 저장소는 건드리지 않습니다. |
| 모두 Fetch | `Shift+F` | 저장소를 하나씩, 진행 상황은 상태 표시줄에 표시하고 실패는 끝에 나열합니다. |
| 모두 Pull | `Shift+P` | 같은 방식이며 fast-forward만 합니다. merge 때문에 멈추는 일이 없습니다. |
| 누락된 저장소 클론 | `m` | 기록된 리모트가 있는 누락된 저장소를 모두 클론합니다. |
| 새 워크스페이스... | `n` | |
| 열린 탭에서... | `a` | 열린 탭이 체크된 새 워크스페이스. |

**누락된** 저장소(폴더가 사라진 저장소)는 표시된 채 목록에 남으며 **위치 지정...**(`l`
또는 `Enter`: 지금 있는 곳을 고릅니다), **클론**(추가할 때 `origin` URL이 기록되었다면),
**제거**(`x`)를 쓸 수 있습니다. 모든 행에는 같은 동작을 담은 `⋮` 메뉴(오른쪽 클릭, `.`
또는 `Shift+F10`)도 있고, 모든 동작은 팔레트의 `워크스페이스:` 아래에 있습니다.

## 새로 만들기 / 편집 양식

![워크스페이스 편집 양식: 이름, 색상, 설명, 기본 프로필, 저장소 체크 목록](../images/workspace-edit.png)

- **이름**: 필수이며 고유해야 합니다.
- **색상**: 테마 색의 드롭다운입니다. 칩과 행의 점 색입니다.
- **설명**: 자유 텍스트.
- **프로필**: 내 `[[profiles]]`의 드롭다운, 또는 "없음". 선택 사항입니다.
- **✦ AI 지침**: AI가 켜져 있을 때만 표시되며, [아래](#워크스페이스의-ai-지침)를 참고하세요.
- **저장소**: GitPoulpi가 아는 모든 저장소(열린 탭, 즐겨찾기, 최근, 그 워크스페이스
  자체의 저장소, 누락된 것 포함)의 체크 목록입니다. `Space`는 행을 체크합니다.
  **폴더 추가...**(`Ctrl+B`)는 디스크에서 저장소를 고릅니다. 새로 추가한 저장소마다
  origin URL을 저장소에서 읽어(자격 증명 없이) 기록하며, 나중에 클론할 때 사용됩니다.

## 워크스페이스의 AI 지침

AI를 켜면(*설정 > AI*) 양식에 **편집...** 버튼이 있는 **✦ AI 지침** 행이 생깁니다(행에서 `Enter`). 이 버튼은 **워크스페이스의 모든 저장소**에서 AI에게 전달할
내용의 작은 편집기를 엽니다: **대상** 목록에서 *모든 AI 작업* 또는 한 동작(commit 메시지, 설명, stash 메시지, pull request, commit 작성기, 충돌 해결, 코드 리뷰)을 고르고,
**결합 방식**으로 *전역에 추가*(전역 지침 뒤에 전송) 또는 *전역 대체*(전역 지침 대신 전송)를 선택한 다음 텍스트를 씁니다. **적용**은 전체 집합을 유지하고,
양식의 **저장**은 이를 워크스페이스와 함께 `workspaces.toml`에 씁니다. **취소**는 입력한 내용을 버립니다. AI가 꺼져 있으면 행이 숨겨지고
워크스페이스의 지침은 그대로 남습니다.

워크스페이스의 지침은 전역 지침과 저장소 자체 지침 사이에 놓입니다(순서와 *대체*가 하는 일은 [AI 지침](ai.md#지침) 참조). 여러 워크스페이스에 속하는 저장소는
창의 활성 워크스페이스가 그것을 포함하면 그 워크스페이스를, 아니면 포함하는 첫 번째 워크스페이스를 사용합니다. 스크립트에서는:
`gitpoulpi workspace set-ai-instructions <id> [--action <a>] [--mode append|replace] (--text ... | --clear)`. `workspace show`는 이를 `ai_instructions`로 출력합니다.

```toml
[[workspace]]
id = "acme"
name = "Acme"
repos = ["/home/u/src/acme-api"]

[workspace.ai_instructions]       # every AI action in this workspace
text = "Use the Acme glossary."
mode = "add"                       # or "replace"

[workspace.ai_overrides.code_review]   # one action
text = "Flag missing tests."
mode = "add"
```

## 기본 프로필

commit은 다음 중 처음으로 해당되는 것으로 서명됩니다.

1. 그 저장소에 **직접** 고른 프로필(도구 모음의 프로필 필드),
2. 저장소가 구성원이라면 **활성 워크스페이스**의 프로필,
3. `general.active_profile`.

도구 모음의 프로필 필드에는 출처가 표시됩니다: "Work - 워크스페이스 Acme에서". 프로필이
하나뿐이어도 워크스페이스의 기본값이 적용되는 동안에는 이 필드가 표시됩니다. 프로필이 더
이상 존재하지 않는 워크스페이스는 그냥 적용되지 않습니다. CLI에서는
`commit --workspace <id>`(또는 `GITPOULPI_WORKSPACE`)가 같은 방식으로 결정합니다.

## 키

| 키 | 동작 |
|---|---|
| `Alt+W` | 워크스페이스 드롭다운 열기 |
| `Alt+J` | 워크스페이스 탭 열기 |
| `n`, `a` | 새 워크스페이스, 열린 탭에서 새로 만들기 |
| `e` | 워크스페이스 편집 |
| `Shift+F`, `Shift+P`, `m`, `l` | 모두 Fetch, 모두 Pull, 누락된 저장소 클론, 위치 지정 |

모두 설정 > 키보드 및 마우스에서 다시 할당할 수 있습니다. 전체 목록은
[단축키](keybindings.md)에 있습니다.
