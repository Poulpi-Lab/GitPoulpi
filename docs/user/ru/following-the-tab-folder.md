# Следование папке активной вкладки

В GitPoulpi может быть открыто несколько репозиториев во вкладках. Оболочка, из
которой вы его запустили, остаётся в своей папке: программа не может сменить
папку своей родительской оболочки. GitPoulpi предлагает два способа получить
оболочку в папке активной вкладки:

- **Выйти и cd сюда**: GitPoulpi завершается, а ваша оболочка переходит в папку
  активной вкладки. Для этого нужна небольшая функция оболочки, которую выводит
  `gitpoulpi shell-init`.
- **Открыть в**: открывает папку активной вкладки в терминале, панели
  мультиплексора, редакторе или файловом менеджере. Настройка оболочки не
  нужна. См. [Открыть в](open-in.md).

```
┌🐙 GitPoulpi vX.Y.Z -- /work/other-repo - Открыть в ▾ ────── ⌕ Глобальный поиск ⚙ × ┐
│ ⌂  main-repo x  other-repo x                  Выйти и cd сюда           │
```

- **Открыть в** находится в строке заголовка, после пути репозитория. Эта кнопка
  скрыта, когда окно слишком узкое.
- **Выйти и cd сюда** находится на правом конце панели вкладок. Эта кнопка видна,
  только если выполняются оба условия:
  - GitPoulpi запущен через функцию оболочки (см. ниже).
  - Активная вкладка - не та папка, в которой вы запустили GitPoulpi.
- Команды всегда есть в палитре (`Ctrl+P`): `Вкладка: выйти и cd сюда`,
  `Вкладка: открыть в...` (`Alt+O`) и `Вкладка: открыть в записи по умолчанию`
  (`Ctrl+Alt+O`). Без функции оболочки `Вкладка: выйти и cd сюда` сообщает,
  как её настроить.

Обычный выход (`q`) никогда не меняет папку вашей оболочки. Это делает только
**Выйти и cd сюда**, если вы не выбрали `auto` (см. ниже).

## Настройка функции оболочки

`gitpoulpi shell-init <shell>` выводит функцию с именем `gp`. Параметр `--name`
задаёт другое имя. Функция запускает `gitpoulpi --cwd-file <временный файл> ...`.
Когда вы выходите через **Выйти и cd сюда**, GitPoulpi записывает папку в этот
файл, а функция переходит в эту папку. GitPoulpi ничего не устанавливает и не
правит: вы добавляете одну строку в файл запуска своей оболочки.

| Оболочка | Добавьте в | Строка |
|---|---|---|
| bash | `~/.bashrc` | `eval "$(gitpoulpi shell-init bash)"` |
| zsh | `~/.zshrc` | `eval "$(gitpoulpi shell-init zsh)"` |
| fish | `~/.config/fish/config.fish` | `gitpoulpi shell-init fish \| source` |
| PowerShell | ваш `$PROFILE` (`notepad $PROFILE`) | `gitpoulpi shell-init pwsh \| Out-String \| Invoke-Expression` |

Затем запускайте GitPoulpi через `gp` вместо `gitpoulpi`. Аргументы передаются
дальше (`gp -s work`), а код завершения - это код завершения `gitpoulpi`.

**Существующий `gp` никогда не заменяется без предупреждения.** Если в вашей
оболочке уже есть команда, псевдоним или функция с именем `gp`, скрипт выводит
предупреждение и ничего не определяет. Выберите другое имя, например
`gitpoulpi shell-init bash --name gpl`. В PowerShell функция заменяет встроенный
псевдоним `gp` (`Get-ItemProperty`) и псевдоним, указывающий на `gitpoulpi`.
Любой другой `gp` сохраняется, с предупреждением.

Каждая команда `gitpoulpi` принимает `--cwd-file`, но файл записывает только TUI.

## Настройка: Следовать папке активной вкладки

Настройки > Открыть в > **Следовать папке активной вкладки** (`ui.tab_dir_follow`):

| Значение | Поведение |
|---|---|
| `buttons` (по умолчанию) | **Выйти и cd сюда** и **Открыть в**, как описано выше. |
| `auto` | Кнопки **Выйти и cd сюда** нет. **Открыть в** остаётся. Каждый выход переводит вашу оболочку в папку активной вкладки (если вы запустили GitPoulpi через функцию оболочки). Запись **Открыть в** по умолчанию выполняется каждый раз, когда вы открываете новую вкладку. |

В режиме `auto` запись по умолчанию выполняется только для вкладок, которые вы
открываете сами: из вкладки «Главная», worktree, клонирования или init. Она не
выполняется для вкладок, восстановленных при запуске, для первой вкладки или
при переключении на уже открытую вкладку.

Старые ключи `ui.terminal_launch` и `ui.terminal_launch_command` перенесены
в список **Открыть в**. См. [Открыть в](open-in.md#старые-ключи).
