# Рабочие пространства

**Рабочее пространство** - именованная группа репозиториев, над которыми вы
работаете вместе (фронтенд, его API, документация). Оно помнит, какие из них
открыты во вкладках, и может нести **профиль commit'ов по умолчанию**, чтобы
commit'ы в этих репозиториях делались с нужной идентичностью без ручного
переключения. Репозиторий может входить в несколько рабочих пространств, а
может не входить ни в одно: «Нет рабочего пространства» - это обычный список
вкладок.

Рабочие пространства хранятся в `workspaces.toml` рядом с `config.toml` и общие
для всех сеансов, окна, CLI и MCP (`gitpoulpi workspace ...`, см.
[справочник по CLI](cli-reference.md)). Рабочее пространство, добавленное, переименованное или удалённое из оболочки или
командой `gitpoulpi workspace ...`, пока окно открыто, появляется само примерно за секунду (вкладка «Рабочие пространства», значок на панели вкладок и его список), без нажатия клавиш. Закрытие или удаление рабочего
пространства никогда не трогает репозиторий на диске. Правки рабочих
пространств - это настройки, как избранное и профили: они не входят в
[отмену и повтор](undo-redo.md), а «Удалить» сначала спрашивает.

## Значок рабочего пространства

Когда у вас есть рабочее пространство, на панели вкладок сразу после `⌂`
появляется значок: цветная точка и имя активного рабочего пространства либо
«Нет рабочего пространства» (тускло). На узкой панели он сжимается до точки, а
на очень узкой исчезает.

![Выпадающий список рабочих пространств над панелью вкладок: «Нет рабочего пространства», Orbit (отмечено), Side projects, Archive и «Управление рабочими пространствами...»; на панели инструментов значок Orbit и профиль «Work - из пространства Orbit»](../images/workspace-switch.png)

- **Щёлкните по нему**, нажмите `Alt+W` или выполните `Рабочее пространство:
  сменить...` в палитре, чтобы открыть выпадающий список: ваши рабочие
  пространства, «Нет рабочего пространства» и «Управление рабочими
  пространствами...» (она открывает вкладку «Рабочие пространства»).
- **Переключение меняет вкладки.** Вкладки, которые были открыты, сохраняются
  для рабочего пространства, которое вы покидаете, а вкладки целевого
  возвращаются (в первый раз - его существующие репозитории). Вернитесь, и всё
  на своих местах. Окно перезапускается, как при смене вкладки; демон остаётся.
- **Рабочее пространство запоминается**: при следующем запуске вы вернётесь в
  него.
- **Закрытие последней вкладки** рабочего пространства оставляет его активным и
  показывает вкладку «Главная».
- **`+` (новая вкладка) при активном рабочем пространстве** добавляет
  выбранный репозиторий в список вкладок и ничего не спрашивает. Чтобы
  включить его в само рабочее пространство, используйте «Добавить в рабочее
  пространство» в правом меню вкладки (или `Рабочее пространство: добавить
  вкладку в рабочее пространство`); «Убрать из рабочего пространства» убирает
  его обратно и оставляет вкладку открытой.

Пока нет ни одного рабочего пространства, значка нет: сначала создайте его на
вкладке «Рабочие пространства» или через палитру.

## Вкладка «Рабочие пространства»

Откройте её из меню кнопки `+`, клавишей `Alt+J` или командой `Рабочее пространство: управление...` в палитре; её `x` (или `Ctrl+W`) закрывает вкладку, а при следующем запуске она остаётся открытой, пока вы её не закроете. Каждое рабочее пространство - строка с цветной точкой, именем,
числом его репозиториев (и сколько из них отсутствует), профилем по умолчанию и
пометкой «активно», когда окно в нём. `Right`, `Space` или щелчок разворачивают
его до репозиториев.

![Вкладка «Рабочие пространства»: Orbit развёрнуто до двух репозиториев, Side projects и Archive с пометкой «отсутствует: 1»](../images/workspaces.png)

| Для рабочего пространства | Клавиша | |
|---|---|---|
| Открыть | `Enter` | Делает его активным и открывает его вкладки. |
| Изменить... | `e` | Форма ниже. |
| Удалить... | `x` | Сначала спрашивает. Репозитории не затрагиваются. |
| Fetch все | `Shift+F` | По одному репозиторию, ход выполнения в строке состояния, сбои перечислены в конце. |
| Pull все | `Shift+P` | То же, только fast-forward: никогда не останавливается на слиянии. |
| Клонировать отсутствующие | `m` | Клонирует каждый отсутствующий репозиторий с записанным remote. |
| Новое рабочее пространство... | `n` | |
| Из открытых вкладок... | `a` | Новое рабочее пространство с отмеченными открытыми вкладками. |

**Отсутствующий** репозиторий (его папки больше нет) остаётся в списке с
пометкой и кнопками **Найти...** (`l` или `Enter`: укажите, где он теперь),
**Клонировать** (если URL `origin` был записан при добавлении) и **Убрать**
(`x`). У каждой строки есть и меню `⋮` (правый щелчок, `.` или `Shift+F10`) с
теми же действиями, а каждое действие есть в палитре под `Рабочее
пространство:`.

## Форма «Новое» / «Изменить»

![Форма изменения рабочего пространства: имя, цвет, описание, профиль по умолчанию и список репозиториев с флажками](../images/workspace-edit.png)

- **Имя**: обязательно, уникально.
- **Цвет**: выпадающий список цветов темы; точка на значке и в строках.
- **Описание**: произвольный текст.
- **Профиль**: выпадающий список ваших `[[profiles]]` или «Нет». Необязателен.
- **✦ Инструкции для ИИ**: только при включённом ИИ, см. [ниже](#инструкции-ии-рабочего-пространства).
- **Репозитории**: список с флажками из всех репозиториев, известных GitPoulpi
  (открытые вкладки, избранное, недавние, свои у рабочего пространства, в том
  числе отсутствующие). `Space` отмечает строку; **Добавить папку...**
  (`Ctrl+B`) выбирает репозиторий на диске. URL `origin` каждого нового
  репозитория читается из репозитория и записывается (без учётных данных), и
  именно его потом использует «Клонировать».

## Инструкции ИИ рабочего пространства

При включённом ИИ (*Настройки > ИИ*) в форме есть строка **✦ Инструкции для ИИ** с кнопкой **Изменить...** (`Enter` на
строке). Она открывает небольшой редактор того, что сообщается ИИ **в каждом репозитории рабочего пространства**:
выберите в списке **Для** *Каждое действие ИИ* или одно действие (сообщение commit'а, объяснение, сообщение stash'а,
pull request, композитор commit'ов, разрешение конфликтов, код-ревью), выберите **Сочетание** - *Добавить к
глобальным* (отправляется после общих инструкций) или *Заменить глобальные* (отправляется вместо них) - и напишите
текст. **Применить** сохраняет весь набор, **Сохранить** в форме записывает его в `workspaces.toml` вместе с
рабочим пространством; **Отмена** отбрасывает набранное. При выключенном ИИ строка скрыта, а инструкции рабочего
пространства остаются как есть.

Слова рабочего пространства лежат между общими инструкциями и инструкциями самого репозитория (порядок и то, что
делает *заменить*, см. в [инструкциях ИИ](ai.md#инструкции)). Репозиторий, входящий в несколько рабочих пространств,
использует активное рабочее пространство окна, если оно его содержит, иначе первое, которое содержит. Из
скрипта: `gitpoulpi workspace set-ai-instructions <id> [--action <a>] [--mode append|replace] (--text ... |
--clear)`; `workspace show` выводит их как `ai_instructions`.

```toml
[[workspace]]
id = "acme"
name = "Acme"
repos = ["/home/u/src/acme-api"]

[workspace.ai_instructions]       # каждое ИИ-действие в этом рабочем пространстве
text = "Use the Acme glossary."
mode = "add"                       # или "replace"

[workspace.ai_overrides.code_review]   # одно действие
text = "Flag missing tests."
mode = "add"
```

## Профиль по умолчанию

Commit подписывается первым из подходящих вариантов:

1. профиль, который вы выбрали **вручную** для этого репозитория (поле профиля
   на панели инструментов),
2. профиль **активного рабочего пространства**, если репозиторий входит в
   него,
3. `general.active_profile`.

Поле профиля на панели инструментов подсказывает, откуда он взят: «Work - из
пространства Acme». Поле показывается и когда профиль всего один, пока действует
профиль рабочего пространства по умолчанию. Рабочее пространство, профиля
которого больше нет, просто перестаёт его применять. В CLI `commit --workspace
<id>` (или `GITPOULPI_WORKSPACE`) выбирает профиль так же.

## Клавиши

| Клавиша | Действие |
|---|---|
| `Alt+W` | Открыть список рабочих пространств |
| `Alt+J` | Открыть вкладку «Рабочие пространства» |
| `n`, `a` | Новое рабочее пространство, новое из открытых вкладок |
| `e` | Изменить рабочее пространство |
| `Shift+F`, `Shift+P`, `m`, `l` | Fetch все, pull все, клонировать отсутствующие, найти |

Все они переназначаются в Настройки > Клавиатура и мышь; полный список - в
[сочетаниях клавиш](keybindings.md).
