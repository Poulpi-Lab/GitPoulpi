# Стеження за папкою активної вкладки

GitPoulpi може тримати відкритими кілька репозиторіїв у вкладках. Оболонка, з
якої ви його запустили, залишається у своїй папці: програма не може змінити папку
своєї батьківської оболонки. GitPoulpi пропонує два способи потрапити в
оболонку в папці активної вкладки:

- **Вийти й cd сюди**: GitPoulpi завершується, а ваша оболонка переходить у
  папку активної вкладки. Для цього потрібна невелика функція оболонки, яку
  виводить `gitpoulpi shell-init`.
- **Відкрити в**: відкриває папку активної вкладки в терміналі, панелі
  мультиплексора, редакторі чи файловому менеджері. Налаштовувати оболонку не
  треба. Див. [Відкрити в](open-in.md).

```
┌🐙 GitPoulpi vX.Y.Z -- /work/other-repo - Open in ▾ ── ⌕ Глобальний пошук ⚙ × ┐
│ ⌂  main-repo x  other-repo x                   Quit & cd here           │
```

- **Відкрити в** розташовано в рядку заголовка, після шляху репозиторію. Його
  приховано, коли вікно завузьке.
- **Вийти й cd сюди** розташовано на правому краї рядка вкладок. Воно
  показується лише тоді, коли виконуються обидві умови:
  - GitPoulpi запущено через функцію оболонки (нижче).
  - Активна вкладка - не та папка, у якій ви запустили GitPoulpi.
- Команди завжди є в палітрі (`Ctrl+P`): `Вкладка: вийти й cd сюди`,
  `Вкладка: відкрити в...` (`Alt+O`) і `Вкладка: відкрити в типовому`
  (`Ctrl+Alt+O`). Без функції оболонки `Вкладка: вийти й cd сюди` підказує, як
  її налаштувати.

Звичайний вихід (`q`) ніколи не змінює папку вашої оболонки. Лише
**Вийти й cd сюди** це робить, якщо тільки ви не виберете `auto` (нижче).

## Налаштування функції оболонки

`gitpoulpi shell-init <shell>` виводить функцію з назвою `gp`. Використайте
`--name`, щоб вибрати іншу назву. Функція виконує
`gitpoulpi --cwd-file <temp file> ...`. Коли ви виходите через **Вийти й cd
сюди**, GitPoulpi записує папку в цей файл, а функція переходить у неї.
GitPoulpi нічого не встановлює й не редагує: ви додаєте один рядок у файл
запуску вашої оболонки.

| Оболонка | Додайте це до | Рядок |
|---|---|---|
| bash | `~/.bashrc` | `eval "$(gitpoulpi shell-init bash)"` |
| zsh | `~/.zshrc` | `eval "$(gitpoulpi shell-init zsh)"` |
| fish | `~/.config/fish/config.fish` | `gitpoulpi shell-init fish \| source` |
| PowerShell | ваш `$PROFILE` (`notepad $PROFILE`) | `gitpoulpi shell-init pwsh \| Out-String \| Invoke-Expression` |

Потім запускайте GitPoulpi через `gp` замість `gitpoulpi`. Аргументи
передаються далі (`gp -s work`), а код завершення - це код завершення
`gitpoulpi`.

**Наявний `gp` ніколи не замінюється без попередження.** Якщо у вашій
оболонці вже є команда, псевдонім чи функція з назвою `gp`, скрипт виводить
попередження й нічого не визначає. Виберіть іншу назву, наприклад
`gitpoulpi shell-init bash --name gpl`. У PowerShell функція замінює
вбудований псевдонім `gp` (`Get-ItemProperty`) і псевдонім, що вказує на
`gitpoulpi`. Будь-який інший `gp` залишається, з попередженням.

Кожна команда `gitpoulpi` приймає `--cwd-file`, але файл записує лише TUI.

## Налаштування: Стежити за папкою активної вкладки

Налаштування > Відкрити в > **Стежити за папкою активної вкладки**
(`ui.tab_dir_follow`):

| Значення | Поведінка |
|---|---|
| `buttons` (типово) | **Вийти й cd сюди** і **Відкрити в**, як описано вище. |
| `auto` | Кнопки **Вийти й cd сюди** немає. **Відкрити в** залишається. Кожен вихід переводить вашу оболонку в папку активної вкладки (коли ви запустили GitPoulpi через функцію оболонки). Типовий пункт **Відкрити в** виконується щоразу, коли ви відкриваєте нову вкладку. |

У режимі `auto` типовий пункт виконується лише для вкладок, які ви відкриваєте
самі: з вкладки Головна, з worktree, клонуванням чи init. Він не виконується
для вкладок, відновлених під час запуску, для першої вкладки, або коли ви
перемикаєтеся на вже відкриту вкладку.

Старіші налаштування `ui.terminal_launch` і `ui.terminal_launch_command`
перенесено до списку **Відкрити в**. Див.
[Відкрити в](open-in.md#застарілі-ключі).
