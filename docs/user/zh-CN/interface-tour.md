# 界面导览

本页按从上到下的顺序，为 GitPoulpi 窗口的每个区域命名。其他页面使用相同的名称。图片使用一个带有虚构作者的小型演示仓库。

![主窗口及其各区域：标签栏、工具栏、引用侧栏、Log、工作更改窗格、commit 表单和状态栏](../images/hero.png)

## 框架

### 标题栏

窗口的顶部边缘显示为 <img src="../../../assets/logo/gitpoulpi.png" alt="GitPoulpi 图标" height="16"> `GitPoulpi vX.Y.Z -- <repository path>`（会话名称在状态栏中，状态栏默认位于底部）。

- **<img src="../../../assets/logo/gitpoulpi.png" alt="GitPoulpi 图标" height="16">** 打开 **关于** 窗口：版本、构建功能、许可证、链接、一段说明 GitPoulpi 是独立项目的简短声明、第三方 crate，以及许可证与致谢。在能显示图像的终端中，章鱼是像素徽标，采用你的徽标颜色（其他终端中仍是 emoji）。命令面板：`帮助：关于 GitPoulpi`；按键：`Ctrl+N` 然后 `A`。在“关于”中，章鱼的瞳孔会跟随鼠标指针。点击徽标（或按 `Space`）可将它旋转到下一种颜色。右键点击徽标（或按 `c`）可查看颜色列表。GitPoulpi 会把你的选择保存在 `ui.logo_color` 中。链接可以点击打开，也可以用各自的访问键打开（`s` 源代码，`d` 文档，`i` 许可证），`l` 会列出第三方 crate 及其版本和许可证（可滚动的列表；`Esc`、`l` 或点击其标题都可返回）。列表中的每个 crate 都带有指向其页面的链接（其代码仓库，没有则是 crates.io 上的页面）：点击该行，或用 `Up` / `Down` 选中后按 `Enter`，即可在浏览器中打开。按 `t`（或使用命令面板的 `帮助：许可证与致谢`）可阅读程序内置的全部内容的许可证声明与致谢，这是一段可滚动的文本（`Up` / `Down`、`PgUp` / `PgDn`、`Home` / `End`；按 `Esc` 或 `t` 返回）。在脚本中，`gitpoulpi licenses` 会输出同样的文本。
- **版本**（`v1.0.0`，有更新的发行版时为 `vX.Y.Z 可用`）位于名称和路径之间：有更新的发行版时，点击会打开更新面板，否则打开 **发行说明** 标签页，见[更新](updates.md)。
- 紧跟在路径之后的 **打开方式 ▾** 会在终端、编辑器、多路复用器或文件管理器中打开标签页的文件夹（`Alt+O`）。参见[打开方式](open-in.md)。
- 齿轮左侧紧邻的 **⌕ 全局搜索**（放大镜及其标签）打开[全局搜索](search.md)（`Ctrl+Alt+F`）。标题栏太窄时，它最先让出位置：先隐藏标签（放大镜保留），再隐藏整个按钮。
- **×** 左侧紧邻的**齿轮**（`⚙`）打开**设置**（`Ctrl+,`）。
- 最右端的 **×** 退出，与 `q` 相同。

![“关于”窗口中的第三方 crate 列表：每行都有名称、版本、指向该 crate 页面的链接和许可证](../images/about-crates.png)

### 状态栏

状态栏默认是窗口的最后一行（**设置 > 外观 > 状态栏位置**可将它移到顶部，位于仓库标签页上方）。它显示当前分支、已加载的 commit 数量（仍有更早的历史待加载时为 `500 / 48213 个 commit`，总数正在统计时以 `…` 代替总数；全部加载后只显示 `2500 个 commit`）、`dirty` 或 `clean`、会话名称、稀疏检出中的 `稀疏` 徽标，以及最有用的按键：`?` 帮助、`Ctrl+G` git 操作、`Ctrl+N` 导航、`Ctrl+P` 命令、`Shift+F10` 菜单、`q` 退出。窗口较窄时，最不重要的按键会被省略。状态栏也会显示状态消息和进度。它显示的按键始终是当前生效的按键，包括你更改过的（参见[设置](settings.md#键盘与鼠标)）。总数如何统计是一项设置（**commits 总数的统计方式**，见[设置](settings.md#日志与图)）。

它的最右端是 **活动** 按钮，会打开活动日志：一个“Git 操作”标签页（各项操作、耗时、消息和错误）、一个“应用程序”标签页（应用程序日志，带级别框和**清空日志**按钮），以及一个范围框，可把两者限定到本仓库、某个工作空间或所有仓库。按钮上的数字统计你还没看过的错误。它左边的任务指示器显示正在运行的后台任务，以及用于取消它的 `[x]`（任务列表中有**全部取消**，命令面板中有 *任务：取消所有可取消的任务*；无法安全停止的任务会说明原因）。**主页**标签页有同样的状态栏，**活动** 按钮在右下角（它会打开范围为“所有仓库”的活动日志）。操作失败时，无论你在哪个视图，状态栏都会用红色显示原因；点击它（或 `活动日志：打开最近的错误`）会打开对应的活动条目，其中有详情、“复制”和建议的下一步操作。两者都在[出错时](troubleshooting.md#出错时)中介绍。

### 浮层

命令面板、帮助、上下文菜单、对话框、弹出窗口和设置都会在窗口之上打开。每一个的边框右上角都有一个 `✕`；按 `Esc` 或点击 `✕` 即可关闭，点击窗口外部则会关闭对话框、弹出窗口或面板（见[关闭窗口和对话框](mouse-and-gestures.md#关闭窗口和对话框)）。

### 窗口很小时

窗口变窄时，不会有东西悄悄消失。按钮先是长标签被截断（以 `...` 结尾），然后换到第二行，或收进所在行的 `⋯` 菜单，而它的按键和命令面板条目始终有效。对窗口来说太大的对话框，不会什么都不画，而是画出一个小框，带有标题、`✕` 和一行**窗口太小：请放大**；`Esc` 和 `✕` 可关闭它，放大窗口后它会完整地回来。

## 标签行

**主页**标签页（房子图标）位于最左端，其后是[工作空间标记](workspaces.md)（有了工作空间后才会出现）、固定的 **Radar** 标签页（和其他标签页一样可以关闭；参见 [Radar](radar.md)），以及你打开过之后的**工作空间**标签页（`Alt+J`；和其他标签页一样可以关闭）。然后每个打开的仓库有一个标签页。关闭标签页的 `x` 只显示在当前标签页和指针下方的标签页上。标签行只放标签页（[全局搜索](search.md)按钮在标题栏中）。

仓库标签页放不下时，这一行会滚动而不是缩小它们：标签页位于两个箭头按钮之间，左边是 `‹`，右边是 `›`。某一侧没有隐藏的标签页时，该侧的箭头会变暗。点击箭头可在该侧多显示一个标签页（按住可持续滚动），也可以在这一行上使用滚轮（向上或向左显示更靠前的标签页）。每当当前标签页变化（你用键盘、标签页选择器或命令面板切换标签页、打开或关闭标签页，或调整窗口大小），这一行都会恰好滚动到能完整显示它。空间足够时，右箭头之后的 `…` 按钮会打开标签页选择器。把标签页拖到箭头上，只要你按住不放，这一行就会滚动，因此可以把它放到屏幕上看不到的标签页之后。`Ctrl+N` 会在每个可用的箭头上显示一个标记。

**设置 > 外观 > 标签栏位置** 可把这一行移到窗口底部（状态栏下方），或变成左边缘的一列：每行一个标签页，先是主页，然后是工作空间标记、Radar、工作空间标签页、各标签页（长名称以 `…` 结尾）和 `+`。标签多于行数时，`…` 行会显示上方（`▲`）和下方（`▼`）隐藏的数量，并打开标签列表；滚轮可滚动该列。与竖排工具栏并用时，标签页位于最外侧。窄于 80 列的窗口仍把标签页放在顶部。点击、关闭叉、中键点击、右键菜单、拖动重新排序和键盘在每个位置的行为都相同。

- 最后一个标签页之后的 **+** 会打开一个小菜单：**新建标签页**（`Alt+T`，命令面板 **标签页：新标签页**），以及在其标签页关闭时出现的 **Radar** 和 **工作空间**（`Alt+J`），用于打开这些标签页；命令面板的 **标签页：新建…** 打开的是同一个菜单。**新标签页**就是：主页视图，搜索框已就绪，所以输入内容会立即筛选你的仓库。选一个（或浏览、克隆、初始化），它的标签页就会出现在标签栏末尾；已经打开的仓库则直接切换过去。在空搜索框中按 `Esc`、`Ctrl+W`、点击它的 `x` 或中键点击会关闭新标签页，并回到你之前所在的标签页。它绝不会保存到你的会话中。

  ![新标签页：搜索框已就绪的主页视图，位于已打开的标签页之上](../images/new-tab.png)
- 右键点击标签页或按 `Ctrl+T`，打开标签页菜单：**新标签页**、**关闭标签页**、**关闭其他标签页…**、**关闭右侧标签页…**、**添加到收藏**（或 **从收藏中移除**）、**添加到工作空间**（或 **从工作空间移除**，在你有工作空间时）、**复制路径**、**打开方式 ›**、**SSH 与凭据…** 和 **稀疏检出…**。
- `Ctrl+PageUp` 和 `Ctrl+PageDown` 切换标签页。`Ctrl+W` 关闭当前标签页。中键点击标签页也会关闭它（并询问同样的问题）。
- `t`（或 `Ctrl+N Tab`）打开标签页选择器，一个可搜索的已打开标签页列表。
- **调整标签页顺序：**按住某个仓库标签页并向两侧拖动（标签页的虚影会跟着指针，一条竖线显示它将落在哪里；`Esc` 取消），或拖动标签页选择器中的一行，在选择器高亮的行上按 `Alt+Up` / `Alt+Down`，或在命令面板中运行 **标签页：左移** / **标签页：右移**。顺序会随会话保存。不移动的普通点击仍然是选中该标签页。房子、工作空间标记和 `+` 永远不会移动。
- 当你通过 `gp` shell 包装器启动 GitPoulpi、并且该标签页不是你启动时所在的文件夹时，标签页右侧会出现 **退出并 cd 到此**。参见[跟随标签页的文件夹](following-the-tab-folder.md)。
- 房子之后的**工作空间标记**（一个彩色圆点加名称，或“无工作空间”）用于切换[工作空间](workspaces.md)：点击它或按 `Alt+W`。有了工作空间后才会出现。

![列出已打开仓库的标签页选择器](../images/tab-picker.png)

开启**记住标签页**（默认）后，你的标签页会在下次启动时恢复。worktree 在自己的标签页中打开，紧跟在其仓库的标签页之后（设置 > 常规 中的 **将 worktree 标签页归在一起**，默认开启）。worktree 被移除时，该标签页会关闭。

### 主页

主页标签页是仓库管理器。它有四个分区：**已打开的仓库**、**收藏**、**最近的仓库**和**所有仓库**。每一行显示分支、领先和落后的数量以及更改的数量，空间足够时再显示文件夹的路径：用 `~` 缩短，较窄时在中间截断，绝不会挤掉名称、所有者或分支。每一行有一颗星（收藏）、**打开**或**切换**、**关闭**或**移除**，以及一个 `⋮` 菜单。

顶部有：**浏览**、**克隆**、**初始化**、一个搜索框、**全部折叠**和**全部展开**。不再存在的文件夹会自行从*最近*和*所有*中消失。缺失的收藏会保留，并带有 **移除** 按钮。**移除**绝不会删除磁盘上的任何东西。

按键：`Enter` 打开、`f` 收藏、`x` 关闭或移除、`y` 复制路径、`o` 用默认工具打开（`⋮` 菜单的**打开方式**可选其他工具）、`.` 菜单、`/` 搜索、`Space` 折叠分区、`Esc` 返回你的标签页。
`Ctrl+N` 会在搜索框、每个分区和每个按钮上显示徽标：按下徽标上的字符即可聚焦或按下该控件（参见[徽标](keybindings.md#徽标)）。

只有一个搜索框，它会筛选其下的所有内容，包括收藏：仓库的名称、分支或路径包含输入的文字就会保留。工作空间不是主页的一个页面，而是独立的标签页：从 `+` 菜单、`Alt+J` 或命令面板打开，用它的 `x` 关闭。参见[工作空间](workspaces.md)。

**克隆** 会针对每个已连接的配置（GitHub、GitLab、Gitea、Forgejo、Azure DevOps、Bitbucket、Gerrit），按所有者分节列出你能访问的仓库：先是你自己的，然后是每个组织或群组（按字母顺序），各自位于一个标题之下。锁形标记表示私有仓库。搜索框会在所有分节中筛选；没有匹配项的分节会消失。`Up` 和 `Down` 会跳过标题，`Home`、`End`、`PgUp` 和 `PgDn` 在列表中同样可用。

![主页标签页：已打开、收藏和最近的仓库，以及“浏览”“克隆”和“初始化”按钮](../images/home.png)

## 工具栏

默认是窗格下方、状态栏上方的一行。**设置 > 外观 > 工具栏位置**可将它放到顶部（标签页下方）、底部，或放成窗格左侧或右侧的一列（窗口窄于 80 列时，列会画成底部的一行）。按钮位于行或列的起始端；**设置 > 外观 > 工具栏按钮对齐**可让它们居中或移到末端。每个按钮都有自己的图标颜色，由主题设定（参见[主题](themes.md)）。放不下所有按钮时，最不重要的按钮会移到 `⋯` 之后。在列中，每个按钮占一行，`▾` 在行尾，菜单在列旁边打开；底部工具栏的菜单向上打开。

| 按钮 | 作用 |
|---|---|
| **撤销**、**重做** | 撤回或恢复上一次操作（`Ctrl+Z`、`Ctrl+Y`）。撤销关闭时隐藏。参见[撤销与重做](undo-redo.md)。 |
| **Pull** `▾` | 按 **设置 > Git 与编码 > Pull 按钮** 所指定的方式 pull。`▾` 列表有 **Fetch 全部**、**Pull（尽可能 fast-forward）**、**Pull（仅 fast-forward）** 和 **Pull（rebase）**。列表项只运行一次，不会改变按钮。 |
| **Push** `▾` | push 已检出的分支。`▾` 列表会一次性 push 到你选择的远程。 |
| **分支** | 在已检出的 commit 处创建分支。 |
| **Tag** | 在已检出的 commit 处创建 tag。 |
| **Stash**、**弹出** | stash 所有更改。弹出最新的 stash。 |
| **LFS** `▾` | Git LFS 操作：fetch、检出、pull、push、清理（`Ctrl+G l`）。Git LFS 关闭时隐藏。参见 [Git LFS](lfs.md)。 |
| **Flow** `▾` | 分支工作流菜单（开始、完成、同步、提升；`Ctrl+G Shift+W`）。只在有工作流的仓库中显示。参见[分支工作流](branching-workflows.md)。 |
| **搜索** | 在 Log 之上打开 commit 搜索栏（`f`）。 |

在末端（一行的右侧，一列的底部），当仓库已关联到托管平台时，一个**标记**会显示已检出分支的 pull request（例如 `GH #12` 或 `GL !53`），或显示暗淡的 `+ PR`。**设置 > 外观 > 将 pull request 按钮固定在末端**（默认开启）让它留在那里；关闭后，它与其他按钮一起排列并随其对齐。参见[托管平台与议题跟踪器](hosting-integration.md)。在列中，配置组合框占最后一行。

在最右端，当你有两个或更多[配置](settings.md#配置)时，**配置组合框**为此仓库选择 commit 身份。第一行*默认*跟随 **设置 > 配置**。选择配置之后，GitPoulpi 会询问是否也把它的名称和邮箱写入仓库的 git 配置（`user.name`、`user.email`）。**写入 git 配置**会写入它们。`Esc` 只在 GitPoulpi 中保留该选择。命令面板：`仓库：更改配置…`。

每个按钮都有对应的命令面板命令和快捷键。

![工具栏下方展开的 Pull 列表：Fetch 全部和三种 pull 方式](../images/pull-push-tooltip.png)

## 横幅

Log 上方的一条带子会告诉你仓库处于特殊状态。它带有指明前进方向的按钮。每个按钮同时也是一条命令面板命令。

| 横幅 | 按钮 |
|---|---|
| merge、cherry-pick 或 revert 因冲突而停下 | **解决冲突…**、**Commit** 或 **继续**、**中止** |
| 正在进行 rebase | **解决冲突…**、**继续**、**跳过**、**中止** |
| **正在应用补丁（git am）** | **解决冲突**、**继续**、**跳过**、**中止** |
| 残留的 `index.lock` 阻止了每一次更改 | **删除 index.lock**（会先询问） |
| auto-stash 没有被放回 | **立即 Pop**、**Show stash**、**重新开始**、**Drop**（可选项取决于状态） |

参见[解决 merge 冲突](merge-conflicts.md)和[故障排除](troubleshooting.md)。

## 引用侧栏（左侧）

所有指向 commit 的名称组成的树。每个分区的标题中有计数、用于折叠的箭头，以及自己的滚动位置。拖动两个分区之间的边框可调整它们的大小。

- 顶部的**筛选**框（`/`）：按名称过滤每个分区。
- **本地**：你的分支，按 `/` 分成文件夹（`feature/`、`fix/`）。对勾标记已检出的分支。你可以在设置中关闭文件夹。
- **远程**：每个远程，其分支位于其下。
- **WORKTREE**：关联的 worktree（如果有，或在你显示了该分区时）。标题上的 **+** 用来创建 worktree；双击某个 worktree 可在它自己的标签页中打开，右键点击它可使用“打开方式”、Merge 和移除。参见 [Worktree](worktrees.md)。
- **STASHES**：你的 stash。右键点击其中一个可使用 **Pop**、**Apply** 和 **Drop**。
- **TAGS**：你的 tag，像分支一样按 `/` 分成文件夹（`releases/`、`backups/`）。箭头表示该 tag 也在远程上。
- **PULL REQUESTS** 和 **议题**：在你连接了托管账号并关联仓库之后。
- **子模块**：子模块及其状态（如果有）。参见[子模块](submodules.md)。

**显示或隐藏分区：** 右键点击分区标题或窗格的空白处，会出现分区的勾选列表（最后一个可见的分区会保留）。该选择按仓库保存，重启后仍然有效；见[左侧窗格的分区](mouse-and-gestures.md#左侧窗格的分区)。

悬停在一行上会显示它的按钮：在 Log 中隐藏或显示该引用，以及**单独显示**（只显示该引用的 commit）。双击本地分支或 tag 可将其检出。右键点击一行可打开它的菜单。侧栏标题中的 `‹` 会折叠侧栏（`Ctrl+N Shift+H`）。

两个侧边窗格（Refs 侧栏 `Ctrl+N Shift+H` 和右侧窗格 `Ctrl+N Shift+L`）都属于 Log：在打开 diff、文件视图或编辑器时显示或折叠其中一个，只对该视图生效。diff 或文件视图还会自动折叠 Refs 侧栏，为内容腾出空间。回到 Log 后，两个窗格都保持你在 Log 中离开时的样子，下次启动时保存的也是这个状态。

## 右侧窗格

右侧窗格跟随 Log 中的选择。

**工作更改**（选中 WIP 行）：

- 标题形如 `main 上有 4 个文件更改`。在有冲突的 merge 期间，还会加上有冲突的文件数。左侧的红色 `✗` 丢弃所有更改（会先询问）。开启 AI 时，右侧的 `✦` 会解释这些更改。
- **路径**或**树**（扁平列表或文件夹，`m`）、**全部折叠**和**查看所有文件**（`a`）。
- **unstaged 的文件**和 **staged 的文件**，各带一个计数以及一个 **全部 stage** 或 **全部 unstage** 按钮。悬停在一行上会显示它的 **stage 文件** 或 **unstage 文件** 按钮。
- 底部的 **commit 表单**：**修订上一个 commit**、**用 AI 撰写 commit**（开启 AI 时）、带字符计数器和 `✦` 按钮的**摘要**、**描述**，以及 **Commit N 个文件的更改** 按钮。

**Commit 详情**（选中某个 commit），从上到下：完整哈希、带头像和日期的作者、父哈希和更改数量，然后是消息（摘要和描述；拖动其下边框可调整大小）。下方的**已更改的文件**窗格以它自己的控件开头：排序切换、**路径** / **树**、**查看所有文件**和一个**筛选文件**框，固定在列表上方，只有列表会滚动。点击文件可打开它的 diff。窗口较矮时，先缩小消息（最少一行），然后才缩小列表。工作更改视图把**路径** / **树** / **查看所有文件**这一行保留在文件列表顶部，位于 unstaged 和 staged 列表之上。

**消息中的链接。** 在消息中输入的网址（`https://...`，或 markdown `[文字](https://...)` 的目标）带下划线，显示手形指针，点击时会先弹出 **打开此链接？** 并显示完整地址，然后才会打开任何内容：消息文本是不可信的。**打开**（`O`）会启动浏览器，**取消**（`C`、`Esc`、叉号）则什么也不做。只提供 `http` 和 `https` 地址。键盘上的对应方式是命令面板命令 `Commit 详情：打开消息中的链接…`，它会询问消息中的第一个地址，并用 **下一个**（`N`）依次切换其他地址。有些终端会在指针下方的地址上自己画下划线，并在带修饰键的点击（通常是 Shift+点击）时自行打开；那是终端的功能，不是 GitPoulpi 的。

每个文件列表在文件、文件夹和空白处都有菜单，并且可以同时选择多个文件（**Ctrl+点击**、**Shift+点击**）；参见[stage 与 commit](staging-and-committing.md)。

## Commit 列

在以某个 commit 的文件 diff、文件视图或 Blame 显示的文件左侧，可以有一列（内置编辑器旁从不显示，因为它编辑的是工作副本：编辑器打开时该列消失，关闭编辑器回到 diff 后又会出现）。它有三种状态：

- **本文件**：只列出该文件的 commit，每个两行（见[文件历史](log-and-history.md#文件历史)）。右侧显示所选 commit 中该文件的版本。
- **全部**：Log 中 commit 的紧凑列表，带图，见下文。
- **隐藏**：视图左侧的细条 `›` 可以把该列带回来（其提示会写明对应的按键）。

视图的按钮栏始终横跨列上方的整个宽度，所以该列打开、关闭或切换列表时，没有按钮会移动。栏上的 **`本文件 │ 全部`** 选择器（同一个控件的两段，宽度始终不变）用于选择列表：点击某一段会显示该列表，如果该列已隐藏则会打开它；该列显示时，点击已选中的那一段会隐藏该列。屏幕上正在显示的列表对应的那一段会亮起；该列隐藏时，它恢复时将使用的那一段带下划线，列表也会保留。它的提示会写明点击、再次点击已选中的那一段和 `Alt+C`。文件历史也仍可从原来的入口打开（文件菜单、命令面板中的 `文件历史：...`）。

![“全部”状态下的 Commit 列，位于某个 commit 的文件 diff 旁，表头为引用、图、消息、作者和日期，引用栏中显示分支和 tag 标签](../images/commit-column-all.png)

- **显示或隐藏**：`Alt+C`（命令面板 `视图：切换 Commit 列`）、点击选择器上已选中的那一段、该列上的 ✕，或细条 `›`。在命令面板中，`视图：Commit 列：隐藏`、`...：文件历史` 和 `...：全部 Commits` 可直接选择状态。这一选择连同当时的列表，会和该列的其他设置一起被记住。没有选择时，“全部”列表由终端宽度决定：终端宽度达到 140 列时显示。旁边的视图会小于 30 列时，不会绘制该列；工作树的 diff 和比较也不会绘制“全部”的图（文件历史仍会显示，因为它不需要 commit）。
- **宽度**：拖动它的右边框（亮起的边框跟随指针），或使用 `视图：加宽 Commit 列` 和 `视图：收窄 Commit 列`。它最多可占中央列的 70%（其余留给视图，视图始终不会小于 30 列）。它和其他尺寸一起被记住。
- **选择 commit**：点击它，或把键盘交给该列（`Ctrl+N` 后按该列的徽标，或 `视图：聚焦 Commit 列`），再用 `Up` / `Down`、`PageUp` / `PageDown`、`Home` / `End`。`Enter` 或 `Right` 转到该 commit 的文件列表，`Esc` 把键盘还给视图。右侧窗格跟随选择：显示该 commit 的详情和它更改的文件，方便你打开它的另一个文件。
- **视图的行为**：已打开的文件保持打开。如果所选 commit 更改了它，视图显示该 commit 中的 diff。如果没有，视图显示当时的文件，并在标题中注明“此 commit 中未更改”。如果该 commit 没有这个文件，视图会这样说明，并保持可用。Blame 仍是 Blame，按所选 commit 的状态显示。

“全部”列表位于一个表头之下（Log 自己的列名）。每行一个 commit：图的泳道、标题（即消息）、作者名和简短日期，如果你开启，还有分支和 tag 标签。它就是 Log 本身的列表，commit 相同、顺序相同，滚动时会加载更早的 commit。泳道的画法与 Log 的“图”列相同：在能显示图像的终端中（参见[选择终端](terminals.md)）绘制为相连的泳道和圆形标记，并且在“图”上开启头像设置时，圆圈里会显示作者的头像；在其他终端中绘制为字符。默认情况下，泳道会占用所需的宽度，标题始终至少保留几个字：列较窄时，先让出作者，再让出日期，然后才会截短泳道。缩到最小宽度，即一个 commit 圆点时，“图”栏与 Log 中一样为紧凑模式：每个 commit 都在同一条泳道上，没有分支线和 merge 线。被窗格截断的栏（行已横向滚动，或“图”栏比可用空间更宽）会保留其图像和头像，在边缘处被裁剪。滚轮滚动指针下的列表。

- **悬停和菜单**：在一行上停留，会显示指针下那一部分的 Log 提示（标题上是完整消息，作者上是姓名和邮箱，日期上是完整日期）。右键点击一行（或在该列拥有键盘焦点时按菜单键、`Shift+F10`；命令面板中为 `视图：Commit 列：所选行的菜单`）会打开它的菜单：*在 Log 中显示*、该 commit 中此文件的 diff、该 commit 时的文件、该 commit 时此文件的 Blame，然后是 Log 自己对该 commit 的菜单（复制、cherry-pick、分支，分隔线下方是会改写内容的行，例如 revert）。前四行在命令面板中也各有一项（`视图：Commit 列：...`）。在“本文件”列表中，各行使用文件历史自己的菜单和相同的提示。
- **调整各栏宽度和横向滚动**：拖动表头的分隔线，可调整它左侧那一栏的宽度：泳道、消息、作者、日期、引用、更改或 SHA。最后一栏也有分隔线：紧随其后的那个单元格（行占满空间时为该列自己的边框），亮起方式相同，用来调整最后一栏的宽度。和 Log 一样（`ui.column_resize`），默认情况下分隔线是两栏之间的分隔单元格，图的行底色到此为止（底色会穿过它，所以它与下一栏之间没有普通单元格）：表头中有一个刻度停在其中，指针在其上或拖动它时，会沿该列画出一条细线，从线上任意一点拖动都可调整宽度；设为 `header` 时，分隔线是下一个名称的首字母，指针在其上时亮起（不画线，只能从表头拖动）。在你调整任何一栏之前，消息使用其余的宽度；第一次拖动会把每一栏（包括消息）固定为它当前的宽度，所以调整一栏只会移动其后的栏，不会改变其他宽度。你调整过的栏会保持宽度，绝不会为腾出空间而缩小：此时如果行比列宽，在该列拥有键盘焦点时，可用 Shift+滚轮、横向滚轮或 `Shift+Left` / `Shift+Right` 横向滚动，底部边框上的滚动条显示当前位置。键盘操作：`Tab` 在已显示的栏中选择，`]` 加宽，`[` 收窄，`0` 把所有栏恢复为自动宽度（命令面板中有 `视图：Commit 列：调整下一栏`、`... 加宽该栏`、`... 收窄该栏`、`... 重置各栏宽度`、`... 向左滚动` 和 `... 向右滚动`）。宽度会被记住。泳道因滚动而被截断时，即使在能显示图像的终端中也会绘制为字符。
- **选择显示的栏**：右键点击表头会打开一个菜单，每一栏一个复选框，Log 提供的每一列都在其中：引用、图、消息、作者、日期、更改和 SHA。消息始终显示。**引用**、**更改**和 **SHA** 默认关闭；显示后，引用显示该 commit 的分支和 tag 标签，更改显示其文件数和 `+添加 -删除` 的行数，SHA 显示其短哈希，都与 Log 自己的列相同。与引用一样，更改和 SHA 绝不会为腾出空间而缩小：行会改为横向滚动。用键盘时，`视图：Commit 列：选择显示的列` 打开同一个菜单（方向键和 `Enter` 选择一行），`视图：Commit 列：切换引用列`、`... 切换图列`、`... 切换作者列`、`... 切换日期列`、`... 切换更改列` 和 `... 切换 SHA 列` 可直接切换某一栏。显示哪些栏、它们的顺序及其宽度只属于该列：它们保存在 `config.toml` 中（`ui.commit_column_columns_visible`、`ui.commit_column_columns_order`、`ui.commit_column_columns_widths`），与 Log 自己的列相互独立，二者绝不会互相改变。
- **移动各栏**：把表头的一个名称拖到另一个名称上，即可把该栏移到那里，与 Log 中一样（行会跟随指针；设为 `ui.column_resize = "header"` 时，名称的首字母是调整宽度的分隔线，所以请按在名称的其余部分上）。任何一栏都可以放到任何位置，包括泳道和引用标签。用键盘时，`Tab` 选择该栏，`<` / `>` 在已显示的栏中把它向左或向右移一位（命令面板中有 `视图：Commit 列：将该栏左移` 和 `... 将该栏右移`）。顺序会被记住。

  ![Commit 列表头的右键菜单：引用、图、消息（始终显示）、作者、日期、更改和 SHA 各有一个复选框](../images/commit-column-menu.png)

鼠标手势也列在[鼠标与手势](mouse-and-gestures.md#commit-列全部列表)中。

## 尺寸会被记住

GitPoulpi 会记住你拖动过的每一个尺寸，跨标签页切换和重启都有效。所有仓库的尺寸相同。这包括 引用侧栏、Log 和右侧窗格之间的分隔条、每个 引用分区的高度、commit 消息块、Log 的列宽、merge 编辑器的窗格，以及文件夹选择器的分隔条。尺寸按窗口的比例存储，所以在宽终端上做出的布局也适合窄终端。

要重置所有尺寸，请运行命令面板命令 `导航：重置布局`。有些尺寸还有自己的重置：`导航：重置引用分区大小`、`Commit 详情：重置消息区大小`，以及在 merge 编辑器中双击分隔条或按 `Alt+0`。

## 浮层与特殊屏幕

- **命令面板**（`Ctrl+P`）：覆盖所有命令的过滤框。每一行显示其快捷键。当前无法运行的命令为灰色，原因显示在底部。命令带有分组前缀，如 `Git：`、`引用：`、`导航：`、`Diff：`、`工作区更改：`、`Commit：`、`视图：`、`仓库：`、`标签页：`、`LFS：`、`Pull request：`、`议题：` 或 `AI：`。输入前缀即可查看其分组。
- **选择器**：有些命令面板命令会打开第二个列表，例如 `应用：更改主题…`、`应用：更改语言…` 和 `应用：更改图配色主题…`。在列表中移动时，窗口会实时显示每个选项。`Enter` 保留它。`Esc` 恢复旧的选择。主题列表有**全部**、**深色**、**浅色**和**彩色**过滤器。参见[主题](themes.md)。
- **帮助**（`?`）：分为多个标签页。**按键** 列出所有按键和手势；其他标签页（开始、Log、更改、引用、托管、设置、AI 与 CLI）是各项操作的简短指南，并说明如何调用每项操作。用 `Tab` / `Shift+Tab`、`Left` / `Right`、`Alt+1`..`Alt+8` 或点击切换标签页。输入文字可过滤当前标签页。`Ctrl+D`，或点击底部的链接，可打开当前标签页对应的文档页面。

  ![帮助的“托管”标签页：简短指南，说明如何调用每项操作](../images/help-hosting.png)

  ![帮助浮层：列出 Ctrl+P、Ctrl+N、Ctrl+G、? 和移动按键的“全局”分区，然后是“鼠标基础”分区](../images/help.png)
- **搜索栏**（`f`）：位于 Log 的右上角。它显示匹配项的 `n of N`。
- **上下文菜单**：右键点击，或在所选行上按 `.`。带 `›` 的行会打开子菜单。
- **对话框**：确认、分支或 tag 名称、克隆、初始化、创建 pull request、push 被拒绝后的选择，等等。`Enter` 接受，`Esc` 取消。
- **交互式 rebase** 和 **commit 撰写器**会用审阅界面取代 Log。参见[使用 Log](log-and-history.md#交互式-rebase)和[stage 与 commit](staging-and-committing.md#commit-撰写器把你的更改拆分成多次-commit)。

  ![commit 撰写器正在审阅四个建议的 commit，每个都带有其文件，以及重置、取消和创建 4 个 commit 按钮](../images/composer.png)

- **设置**（`Ctrl+,` 或标题栏中的齿轮）：左侧是页面列表，右侧是该页面的选项。参见[设置](settings.md)。

  ![设置：左侧是带搜索框的页面列表，右侧是“常规”页面](../images/settings.png)

- 用于较长回答的**弹出窗口**，例如 AI 的**解释更改**弹出窗口（`↑` `↓` 滚动、`c` 复制、`Esc` 关闭）。

  ![“解释工作更改”弹出窗口，带有 AI 的解释和一份需要再次核对的事项清单](../images/ai-explain.png)

弹出窗口中的所有列表操作方式相同。参见[快捷键](keybindings.md)和[鼠标与手势](mouse-and-gestures.md)。

## 本文档中使用的词

| 词 | 含义 |
|---|---|
| 窗格 | 三列之一：引用侧栏、Log（或打开的文件）、右侧窗格。 |
| 标签 | 引用列中的分支或 tag 标签。 |
| WIP 行 | Log 顶部的工作更改行。 |
| Hunk | diff 中一块已更改的行。 |
| 撰写器 | commit 表单，以及把更改拆分成多个 commit 的 AI 审阅。 |
| 键序 | 一个按键后跟另一个按键，例如 `Ctrl+G` 然后 `s`。 |
| 前缀 | `Ctrl+G`（git 操作）或 `Ctrl+N`（导航）。 |
| 徽标 | `Ctrl+N` 显示在控件旁边的字母。按下它即可聚焦该控件。 |
