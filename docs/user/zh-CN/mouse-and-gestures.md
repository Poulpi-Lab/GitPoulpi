# 鼠标与手势

鼠标能做的一切，都有对应的键盘操作。参见[快捷键](keybindings.md)。各区域的名称见[界面导览](interface-tour.md)。

## 通用规则

- **点击**一行即可选中它。这适用于每个窗格、列表、菜单和对话框。
- **双击**一行可打开或运行它。双击本地分支、tag 或引用标签会将其检出。双击仓库行会打开该仓库。
- **右键点击**一行可打开它的菜单。`.`、`Shift+F10` 或菜单键会为所选行打开同一个菜单。
- **滚轮**滚动指针下方的区域。在列表中，它只移动视图。选择保持原位，即使它滚出了视野。只有点击或按键才会移动选择。
- **Shift+滚轮**横向滚动，适用于关闭自动换行时的 diff、文件视图和编辑器。
- **悬停**在按钮、行或滚动条滑块上会使其亮起。许多终端无法改变鼠标指针，所以这种亮起往往是某物可点击的唯一标志。把指针停在按钮或 Log 单元格上会显示工具提示。
- **点击文本框之外**即可离开它。你输入的内容会保留。引用过滤器会应用你输入的内容，与 `Enter` 相同。Log 搜索栏会关闭，与 `Esc` 相同。

## 关闭窗口和对话框

每个带边框的窗口和对话框，边框右上角都有一个 `✕`，各处规则相同：

- **点击 `✕`** 即可关闭。`Esc` 的效果相同，并且会先关闭最里面的一层（打开的下拉列表、文本框、确认框），再关闭窗口。
- **点击外部**会关闭对话框、帮助或信息面板以及弹出窗口。点击外部不会关闭整页视图（设置、Diff 视图、文件视图、各编辑器、评审、看板）：它们没有“外部”。
- 点击面板**内部**永远不会关闭它。
- 含有你已输入文字的表单（新建议题、pull request 或 merge request）会忽略点击外部，免得误点丢失内容。`✕` 和 `Esc` 会先询问**丢弃更改？**；选**继续编辑**即可返回。什么都没输入的表单会立即关闭，单行对话框也是如此。
- 命令面板、选择器（标签页、主题、语言）、审查、看板、合并和编写器中的小对话框以及确认提示也带有 `✕`。上下文菜单和下拉列表没有：按 `Esc` 或点击外部即可关闭。

## 设置中的列表

设置中的列表（配置、AI 配置、工作流、打开方式、图像）这样使用鼠标。**点击子标签页**（常规或列表）可切换到它；`Alt+Left` / `Alt+Right` 效果相同。

- **点击**某一行选中它，**双击**转到它的字段，**滚轮**滚动但不改变选中项。
- **按住某一行并拖动**可上下重新排序：一条横线显示它将落在哪里，松开即放下，`Esc` 取消。键盘对应的是 `Alt+Up` / `Alt+Down`。
- **点击列表下方的 `+ 添加`、`创建副本`、`删除`、`↑`、`↓`**。按键：`Insert`、`Ctrl+D`、`Delete`、`Alt+Up` / `Alt+Down`；见[设置](settings.md#列表)。

## 弹出窗口中的列表

这些规则适用于带过滤字段的弹出窗口中的每个列表：命令面板、它的选择器（主题、语言、图配色）、标签页选择器、可搜索的下拉列表、议题引用列表和帮助。

- **点击**一行即可选中它。
- **双击**一行可运行或选取它，与 `Enter` 相同。
- **滚轮**滚动列表。它不会移动选择。
- 当列表比弹出窗口长时，右边缘会出现**滚动条**。拖动滑块或点击滑轨。

没有过滤字段的短下拉列表在第一次点击时就会选取该行。上下文菜单在第一次点击时就会运行该行。这些列表的按键见[快捷键](keybindings.md#可筛选的弹出列表)。

## 滚动条

每个可滚动的区域在内容放不下时，都会在其边框上显示一条细滚动条：Log、引用分区、文件列表、diff、文件视图、编辑器和弹出窗口中的列表。

- **拖动滑块**进行滚动。
- **点击滑轨**向点击方向移动一页。在 Log 和文件列表中，视图会跳到点击处。
- **在末端箭头上按住按钮**可持续滚动。稍有延迟后开始。移开箭头即可暂停。
- 滚动条只移动视图。它绝不会移动选择。

在 diff 和编辑器中，垂直滚动条还会用小标记显示整个文件：绿色表示添加的行，红色表示删除的行，琥珀色表示更改的行，`◆` 表示光标所在行，`▌` 表示所选文本出现的其他每个位置。merge 编辑器在其滚动条上标出每个冲突。点击标记即可前往。

## 失败和活动日志

- **点击状态栏里的红色错误**，在活动日志中打开对应条目；**点击条目上的“复制”/建议的按钮**（重试、先 Pull、Stash 后重试、打开集成）。
- **点击状态栏最右端的“活动”**打开活动日志。点击标签页切换，点击某个级别的复选框（或 **全部** / **无**）来显示或隐藏这些行，点击“仓库”中的条目打开它的详情，在“应用程序”标签页上点击**清空日志**（会先询问）。用 `Shift` + 滚轮或水平滚动条横向滚动长行。参见[活动日志](troubleshooting.md#活动日志)。
- **点击状态栏右侧任务指示器的 `[x]`** 取消正在运行的任务，**点击其标签**打开任务面板。主页标签页右下角的**活动**按钮（或 `Ctrl+N Shift+G`）会在“所有仓库”范围上打开活动日志（它的范围框是标签页下方的下拉列表，可选择某个仓库或某个工作空间）。

## 调整大小

- **拖动分隔条**，位于 引用侧栏、Log 和右侧窗格之间。键盘一次移动一档：`Ctrl+N Left` / `Ctrl+N Right` 移动引用 | Log 之间的分隔条，`Ctrl+N Shift+Left` / `Ctrl+N Shift+Right` 移动 Log | 右侧窗格之间的分隔条（分隔条朝箭头所指的方向移动）。
  拖过最小宽度会折叠该窗格。键盘上的对应操作是 `Ctrl+N Left` / `Ctrl+N Right`（引用窗格与 Log 之间的分隔条）和 `Ctrl+N Shift+Left` / `Ctrl+N Shift+Right`（Log 与右侧窗格之间的分隔条），每次一档，分隔条朝箭头所指的方向移动；命令面板里对应的是 `导航：加宽引用窗格`、`导航：收窄引用窗格`、`导航：加宽状态窗格`、`导航：收窄状态窗格`，以及 `导航：折叠/展开引用窗格` / `导航：折叠/展开状态窗格`。
- **拖动 引用分区的下边框**可更改其高度。
- **拖动右侧窗格中 commit 消息块的下边框**。
- **拖动两个 Log 标题之间的边框**（默认是那个间隙，可从表头或表格中的任意位置拖动；设置 > Log 与图 > 列宽调整）可调整列宽（键盘：先按 `Shift+C` 选择一列，再按 `]` / `[`）。
- **双击两个 Log 标题之间的边框**可把其左侧的列调整为适合其内容的宽度（键盘：先按 `Shift+C` 选择一列，再按 `=`；`+` 调整所有列）。最后一列在它自己的最后一个单元格上有把手：拖动可调整该列，由消息列补上差值。
- **横向滚动 Log**（`scroll` 列布局；设置 > Log 与图 > 列布局，或选择器的 `横向滚动` 复选框）：表格上的横向滚轮或 `Shift`+滚轮、底部边框上的滚动条（拖动滑块、点按空白轨道、点击两端箭头），或 `Shift+Left` / `Shift+Right`。在默认的 `fit` 布局中，各列填满窗格，没有可滚动的内容。
- **拖动一个 Log 标题**可移动该列：其名称的虚影跟随指针，它离开的标题变暗，一条强调色竖条标出它将落下的位置。松开时各列才会移动；按 `Esc` 取消，携带期间指针显示张开的手（键盘：先按 `Shift+C` 选择一列，再按 `<` / `>`）。

GitPoulpi 会记住每个尺寸。参见[尺寸会被记住](interface-tour.md#尺寸会被记住)。

## 标题栏、标签行和工具栏

- **点击标题栏中的 🐙** 打开**关于**。在“关于”中，章鱼的瞳孔会跟随指针；点击徽标可将它旋转到下一种颜色，右键点击可查看颜色列表，点击链接可打开它。
- **点击标题栏中的打开方式 ▾** 查看程序列表。参见[打开方式](open-in.md)。
- **点击标题栏中的版本号**（`v1.0.0`，或 `vX.Y.Z 可用`）打开“发行说明”标签页。
- **点击标题栏中齿轮左侧的放大镜和 `全局搜索`**，打开[全局搜索](search.md)。
- **点击标题栏中 × 左侧的齿轮**打开设置。
- **点击标题栏最右端的 ×** 退出。
- **点击标签页**切换到它。**点击它的 `x`**（显示在当前标签页和指针下方的标签页上）关闭它。将标签页**向旁边拖动**可调整其顺序。**右键点击标签页**打开标签页菜单。
- **中键点击标签页**会关闭它，与它的 `x` 相同。
- **点击标签页两端的 `‹` 或 `›`**（标签页放不下时显示）可把这一行滚动一个标签页；按住按钮可持续滚动，也可以在这一行上使用滚轮。把标签页拖到箭头上同样会滚动这一行。每当当前标签页变化，这一行也会自动滚动以显示它。
- **点击最后一个标签页之后的 `+`** 会打开一个菜单：新建标签页（`Alt+T`），以及在其标签页关闭时出现的 Radar 和工作空间（`Alt+J`）。
- **点击房子图标**进入主页标签页。
- **点击 Radar 或工作空间标签页**打开它；它的 `x`、中键点击或 `Ctrl+W` 会关闭它。**点击工作空间标记**（`Alt+W`）切换工作空间。
- **点击“退出并 cd 到此”**（通过 `gp` shell 包装函数启动 GitPoulpi 时，显示在标签页右侧）可退出，并让你的 shell 停在活动标签页的文件夹中。参见[跟随活动标签页的文件夹](following-the-tab-folder.md)。
- **点击工具栏按钮**运行它。**点击 Pull、Push 或 LFS 旁的 `▾`** 查看其列表。**点击 `⋯`** 查看放不下的按钮。
- **点击工具栏最右端的配置组合框**，选择此仓库的 commit 身份。

## 主页标签页

- **点击**一行选中它。**双击**它打开该仓库。
- **点击星标**添加或移除收藏。
- **点击一行上的打开、切换、关闭或移除**，或点击 **`⋮`** 打开该行的菜单。**右键点击**一行可得到同一个菜单。
- **点击分区标题**折叠该分区。
- **点击顶部的浏览、克隆、初始化、全部折叠或全部展开**，以及分区标题上的**关闭所有标签页**或**全部移除**。

在**浏览**文件夹选择器中：点击某个位置或文件夹前往，双击文件夹打开它，点击路径字段输入路径。勾选**显示同级文件夹**（`Alt+S`，会被记住），左侧树还会列出每一级已展开目录中的其他文件夹：位于当前路径上的文件夹显示 `▾`，其他显示 `▸`，点击其中一个即可前往。在**克隆**和**初始化**中：点击字段即可输入，点击按钮或复选框即可使用它。

## 引用侧栏

- **点击**一行选中它。**双击**本地分支或 tag 会将其检出。**双击** worktree 或子模块会在标签页中打开它。
- **悬停**在一行上会显示其左侧的图标。**点击**它可在 Log 中隐藏该引用，或再次显示它。**单独显示**开启时，同一位置用于单独显示该引用。在文件夹行上，该图标作用于文件夹中的每个引用。
- **点击侧栏标题中的停止单独显示**或**显示全部**，可清除所有单独显示或所有已隐藏的引用。
- **右键点击**一行打开它的菜单：检出、merge、fast-forward、rebase、创建 worktree、重命名、删除、隐藏、单独显示，等等。远程自己的行有 **Fetch**、**编辑**、**移除** 和其他远程操作。stash 有 **Pop**、**Apply** 和 **Drop**。灰色的行会说明它为什么不能运行。
- **点击 REMOTE 标题上的 `+`** 添加远程。
- **点击文件夹行**折叠或展开它。

## Log

- **点击**一个 commit 选中它。它的详情会出现在右侧窗格中。
- **Ctrl+点击**把 commit 加入选择或从选择中移除。**Shift+点击**选择一个范围（在把 Shift+点击留给自身文字选择的终端中，如 kitty 和 Windows Terminal，请用 **Alt+点击**）。右键点击已选中的 commit 可将它们全部 cherry-pick。选择可以包含 WIP 行和 stash；选中两行或更多行会把右侧窗格变成比较，参见[比较 commit](log-and-history.md#比较-commit)。
- **点击比较窗格中的卡片**会把 Log 光标移到那一行；**点击“交换”**会对调起点和终点两端。在某一行上点击会退出比较。
- **点击 WIP 行**查看工作更改。**点击它的 `// WIP` 文字**可在那里输入 commit 摘要。
- **悬停**在单元格上可查看完整文本：消息、作者和邮箱、完整日期、完整哈希。
- **悬停在 `+N` 徽标上**可查看该 commit 上的其他引用。移入弹出窗口即可点击其中的引用。双击弹出窗口中的引用可将其检出。
- **双击引用标签**将其检出。
- **右键点击 commit** 打开 commit 菜单。该 commit 上的每个引用各有一个子菜单。
- **右键点击引用标签**会得到一个同时包含该引用的操作和该 commit 的操作的菜单。
- **右键点击标题**可显示或隐藏列：这是一个复选清单（`[x]` / `[ ]`），标题中带 ✕；点击一行，或用方向键和 `Space` / `Enter`，然后用 ✕、`Esc` 或点击别处关闭（命令面板：`视图：Log：选择要显示的列`）。复选框下方有：`按内容调整<列>宽度`（被右键点击的那一列）、`按内容调整所有列宽度` 和 `重置各列宽度`。键盘上的对应操作：`Shift+C` 选择一列，再按 `.`（或 `Shift+F10`）就会在该列上打开同一个菜单。
- **Radar 的列**用法相同：拖动仓库列、`#` 列、作者列或时间列之后的分隔线可调整其宽度，**双击它**可把该列调整为适合其最宽条目的宽度（`C` 选择一列，再按 `=`；`+` 调整所有列），**右键点击列标题**（或先按 `C`，再按 `.`）可选择 `按内容调整<列>宽度` 和 `按内容调整所有列宽度`。
- **点击搜索栏中的 `↑`、`↓` 或 `✕`**，可前往上一个或下一个匹配项，或关闭该栏。
- **点击右侧窗格中 commit 消息里的 `#12`、`ABC-12` 或 `AB#12`**，可在浏览器中打开该议题或 pull request。

### 左侧窗格的分区

**文件夹**（名为 `a/b/c` 的分支和 tag，以及右侧窗格树视图中的文件）可以一次全部折叠或展开：在有文件夹的分区上，**右键点击标题或分区的空白处**，可选择**全部展开** / **全部折叠**（还有**显示/隐藏分区…**，它通向下面的清单）；**右键点击文件夹行**，可选择**展开所有子文件夹** / **折叠所有子文件夹**（该文件夹及其下的一切）。按键在 Refs 窗格、未暂存和已暂存列表以及某个 commit 的已更改文件中都一样：`=` 全部展开，`-` 全部折叠，`*`（或 `Shift+Right`）展开光标所在的文件夹及其下的一切，`_`（或 `Shift+Left`）折叠它。命令面板：*Refs：展开所有文件夹*、*Refs：折叠所有文件夹*、*Refs：展开所选文件夹及其子文件夹*、*Refs：折叠所选文件夹及其子文件夹*，以及针对当前聚焦文件列表的四个*文件：*对应命令。名称筛选生效期间（Refs 筛选、某个 commit 的*筛选文件*），每个含有匹配项的文件夹都会显示为展开状态，无论你原来折叠了什么，而你自己的折叠既不会被改动也不会被保存：清除筛选后它们就恢复了。筛选期间你做的折叠只作用于当前显示的内容，并随筛选一起被忘记。

**右键点击某个分区标题**（没有文件夹的分区，或左侧窗格的空白处），会得到一份分区清单：本地、远程、Worktree、Stash、Tag、Pull request、议题和子模块。点击会取消勾选或勾选一个分区；菜单保持打开。隐藏的分区不会绘制，键盘也会跳过它。最后一个可见的分区不能取消勾选。这个选择按仓库保存，重启后仍保留；没有自己选择的仓库沿用默认设置（全局的 `ui.sidebar_sections_hidden`）。*用于所有仓库* 会把当前选择设为默认，*恢复默认* 会丢弃该仓库自己的选择（命令面板：*左侧窗格：将此分区设置用于所有仓库*）。命令面板：*左侧窗格：显示/隐藏分区…*、每个分区各有一条 *显示/隐藏* 命令，以及 *将分区恢复为默认*。

### 拖动引用

在 引用侧栏中的分支上，或 Log 中的引用标签上按住并将其拖到另一个分支上。状态栏会说明你携带的是什么。能接受放置的目标会亮起。松开即可得到菜单。`Esc` 取消拖动。

| 拖动 | 菜单 |
|---|---|
| 本地分支 X 拖到本地分支 Y 上 | **把 X merge 到 Y**、**把 X rebase 到 Y 上**、**交互式 rebase X 到 Y…**、**把 Y fast-forward 到 X** |
| 本地分支拖到远程分支上 | **Push X** 到该远程 |
| 远程分支拖到本地分支 Y 上 | **Merge**、**把 Y rebase 到它上**、**把 Y fast-forward 到它**，以及当它是 Y 的上游时的 **Pull** |

当操作会改变一个未检出的分支时，GitPoulpi 会先检出它。如果 git 拒绝检出，则不会有任何更改。tag 不能被拖动，也不能接收放置。

键盘：“先标记再放下”对任意两个引用都与拖动效果相同。在引用窗格中对某个分支按 `m`（命令面板：`引用：标记为拖放来源`）。该引用会显示 `◆` 并带下划线，它在 Log 中的标签上也是如此，状态栏会告诉你接下来去哪里。选择另一个引用（任何分区均可）并按 `Shift+M`（命令面板：`引用：将标记的引用放到此处…`）：会出现拖动时打开的同一个菜单，其中各行的运行方式与拖动之后完全相同。菜单打开后标记即用完；`Esc`，或在已标记的引用上再按 `m`，可提前清除标记。命令面板命令 `引用：将所选引用放到已检出分支上…` 会为所选引用和当前分支打开该菜单。

## 右侧窗格

### 工作更改

- **点击**文件打开它的 diff。**再次点击同一文件**返回 Log。如果该文件在编辑器中打开且有未保存的更改，GitPoulpi 会先询问。
- **悬停**在一行上会显示它的 **stage 文件** 或 **unstage 文件** 按钮。文件夹行有 **stage 文件夹** 或 **unstage 文件夹**。
- **点击分区标题上的 全部 stage 或 全部 unstage**。
- **点击分区标题**（`unstaged 的文件`、`staged 的文件`）将其折叠。
- **点击路径或树**选择扁平列表或文件夹。**点击全部折叠或全部展开**可折叠每个文件夹。
- **点击标题左侧的 `✖`** 丢弃所有更改（会先询问）。**点击右侧的 `✦`** 用 AI 解释这些更改。
- **右键点击文件**打开它的菜单：stage、丢弃、忽略、LFS、stash 该文件、历史、blame、用外部程序打开、复制路径、创建补丁、编辑、删除。有冲突的文件以 **Resolve using ...** 各行开头。
- **右键点击文件夹行**打开文件夹菜单：stage、丢弃、忽略、stash、创建补丁、打开文件夹、在其中创建文件。
- **右键点击“unstaged 的文件”的空白处**可使用**创建文件**。
- **忽略**、**视为二进制** 和 **视为文本**（文件和文件夹菜单）会先打开一个列表，列出规则可写入的 `.gitignore` 或 `.gitattributes` 文件。点击一行并按 `Enter`（或使用方向键）即可写入；`Esc` 或在外部点击会取消且不写入任何内容。
- 在文件或文件夹行上 **Ctrl+点击** 可加入或移除选择，**Shift+点击**（**Alt+点击**）选取范围；commit 修改的文件和“查看所有文件”中也一样。普通点击会重新开始。**在选中的行上右键点击**：所有选中文件的菜单。
- **在列表空白处右键点击**还提供 **打开仓库文件夹**；Unstaged 另有 **全部 stage** 和 **丢弃所有更改…**，Staged 另有 **全部 unstage**。
- **转换**（文件、文件夹和选择菜单）会重写磁盘上文件的编码、行尾或缩进；一次 `Ctrl+Z` 撤销整个批次。

### Commit 表单

- **点击**摘要或描述即可在其中输入。
- **点击修订上一个 commit** 打开或关闭 amend。
- **点击 Commit N 个文件的更改** 进行 commit。按钮为灰色时，点击会说明原因（例如*请先 stage 要 commit 的更改*）。
- **点击摘要右侧的 `✦`**，用 AI 撰写消息。
- **点击摘要末尾的 `#▾`** 查看议题列表。点击其中一个可插入它的引用。
- **点击用 AI 撰写 commit** 打开 commit 撰写器。

### Commit 详情

- **点击**已更改的文件打开它的 diff。**再次点击**返回 Log。
- **拖动**消息的下边框可调整其大小。把滚轮放在消息上可滚动较长的描述。
- **右键点击**摘要、描述或作者区域，可选择 *修订摘要…*、*修订描述…* 或 *修订作者…*；**双击**其中之一（或作者日期），会打开完整的修订对话框，光标就在该字段中。对应的键盘操作是 `Ctrl+G Shift+E`（所有字段）和 `Ctrl+G Shift+A`（作者）；摘要和描述在命令面板中。
- 在修改的文件、文件夹行、列表空白处或选择上**右键点击**可打开其菜单（打开、历史、blame、在程序中打开、复制路径、忽略、视为二进制或文本、转换、从 commit 恢复、删除）。**Ctrl+点击**和 **Shift+点击**可选择多个文件。

参见[stage 与 commit](staging-and-committing.md)。

## Diff 和文件视图

- **点击 diff 上方栏中的按钮**：文件视图、Diff 视图、Blame、`本文件 │ 全部` 列选择器、编辑、`↑` `↓`、内联、分栏、Hunk、WS、换行、缩略、编码。开启的按钮会高亮。点击 `本文件` 或 `全部` 会在 commit 列中显示该列表；点击已选中的那一段会隐藏该列（见 [Commit 列](interface-tour.md#commit-列)）。
- **点击标题中的 `✕`** 关闭文件。
- **悬停在 hunk 上**会显示 **stage Hunk** 或 **unstage Hunk**，以及 **丢弃 Hunk**。
- **悬停在已更改的行上**会在该行最右端显示它自己的 **+ Stage**、**− Unstage** 和 **✖ 丢弃** 按钮。
- **右键点击某一行**打开 hunk 菜单：stage、unstage 或丢弃该 hunk 或所选的行、文件历史、blame、复制。
- **点击缩略图**可把视图移到那一行。按住按钮并移动可滚动。

每次丢弃都会先询问。丢弃会删除未跟踪的文件时，变成完全空的文件夹也会一并删除（仍包含已跟踪、被忽略或隐藏文件的文件夹，以及本来就是空的文件夹不会被删）；撤销会把文件连同它们的文件夹一起恢复。

### Blame 和文件历史

- **Blame。** 把指针停在注释上可看到 hunk 卡片；点击选中一个 hunk，右键打开它的菜单。拖动注释列的边框可调整宽度（会保存）。在缩略图上点击或拖动来滚动。
- **文件历史。** 点击选中一个 commit；`Shift+点击` 选择要比较的范围；双击在 Log 中显示该 commit；右键打开行菜单；拖动列表与 diff 之间的边框调整宽度；点击列表上的 ✕ 隐藏它（点击 `›` 细条可带回）；点击栏上的 `文件视图` / `Diff 视图` / `Blame` 切换右侧的显示内容，点击 `本文件 │ 全部` 选择器则选择该列的列表。滚轮滚动指针下方的那一半。每一项都有对应的键盘操作（[Blame](log-and-history.md#blame)、[文件历史](log-and-history.md#文件历史)）。

### Commit 列（全部列表）

- **悬停在一行上**会显示 Log 的提示（按指针下的部分显示完整消息、作者的姓名和邮箱、完整日期）。
- **右键点击一行**打开它的菜单：在 Log 中显示、该 commit 中此文件的 diff、该 commit 时的文件、它的 Blame，然后是 Log 对该 commit 的菜单。在键盘上，菜单键效果相同。
- **拖动表头的分隔线**（`ui.column_resize`：默认是两栏之间那个单元格宽的分隔单元格，表头中用暗色 `│` 标出，指针在其上时沿该列画成强调色线，从线上任意位置拖动都可调整宽度；设为 `header` 时是下一个名称的首字母，指针在其上时亮起）可调整它左侧那一栏的宽度：泳道、消息、作者、日期、引用、更改或 SHA。最后一栏之后的那个单元格是最后一栏的分隔线。
- **双击表头的分隔线**可把它左侧那一栏调整为适合其内容的宽度，与 Log 的分隔线相同：即能完整显示其最宽一行的宽度，但不会超过该列的宽度（键盘上：点击一行或按 `Ctrl+N` 让该列获得按键，用 `Tab` 选择该栏，再按 `=`；`+` 调整所有栏；命令面板有 `按内容调整该列宽度` 和 `按内容调整所有列宽度`）。消息栏占用其他栏剩下的空间。
- **把表头的一个名称拖到另一个名称上**可把该栏移到那里：虚影、变暗的来源和强调色竖条都与 Log 的表头相同，松开时该栏才会移动（`Esc` 取消；键盘上先按 `Tab`，再按 `<` / `>`，每次移动一位，效果相同）。
- **右键点击表头**可选择显示哪些栏（引用、图、作者、日期、更改、SHA；消息始终显示）；该清单的标题中带 ✕。其下方是：`按内容调整<栏>宽度`（被右键点击的那一栏）和 `按内容调整所有列宽度`。命令面板有 `选择显示的列`（在键盘上即对 `Tab` 选中的那一栏打开的菜单）和每栏一个切换命令。
- 行比列宽时，**Shift+滚轮**或横向滚轮可横向滚动各行。
- **拖动该列的右边框**可调整其宽度。**点击 `›` 细条**（或该列上的 ✕，或**点击**栏上 `本文件 │ 全部` 选择器中**已选中的那一段**）可恢复或隐藏该列。

### 选择和复制文本

你可以选择并复制 diff、文件视图、Blame 和文件历史中的文本。

- **按下并拖动**以选择文本。滚动时，选择会保持在同一段文本上。
- **双击**选择一个单词。
- **单纯的点击**不会选择文本。它会移动光标或选中该行，并清除文本选择。
- **`y` 或 `Ctrl+C`** 复制所选内容。没有选择时，它们复制当前行。
- 在 diff 中**右键点击**可使用 **复制所选内容**、**复制行** 和 **复制 hunk**。

GitPoulpi 只复制文件的文本。行号、`+` 和 `-` 标记、hunk 标题和 Blame 列都不会被复制。在分栏中，选择会停留在你开始拖动的那一侧。

在 diff 中，拖动同时也会选中它经过的行，与 `v` 相同。然后 `Enter` 会 stage 这些行。`Esc` 先清除文本选择，再清除行选择，最后关闭 diff。

选择文本还会给 diff 和编辑器中该文本出现的其他每个位置着色。

## 移动对话框和调整对话框大小

对话框可以移动，较大的窗口还可以调整大小：

- **拖动标题栏**移动对话框（关闭的叉号仍然响应点击）。命令面板和选择器没有单独的标题栏：拖动上边框。
- **拖动左边框、右边框或下边框**，或某个下角（`◢` 把手）来调整窗口大小。对话框始终留在屏幕内，也不会小于其最小尺寸（撤销历史为 60 x 16，其他的更小）。调整过大小的窗口会充分利用空间：文本区域和列表变大，文字按新宽度换行。
- 指针离开对话框后拖动仍会继续，在对话框外松开绝不会关闭它。
- **拖动分隔条**可调整撤销历史的 Reflog / 丢失的工作视图内部的比例；双击分隔条可重置。
- 键盘上的对应操作是 `Ctrl+N` 然后按 `m`（方向键移动，`Shift`+方向键调整大小，`0` 重置，`Enter` 或 `Esc` 退出）和用于分隔条的 `Alt`+方向键；命令面板中有 `对话框：移动或调整大小` 和 `对话框：重置位置和大小`。它们作用于最上层的对话框。`Ctrl+N` 在所有界面上的作用相同：它会在最前面的窗口、对话框或弹窗的控件（输入框、列表、标签页、按钮和关闭叉）上显示徽标，其后的按键按下该控件，`m` 启动调整模式，`Esc` 取消；状态栏会写明 `<徽标>`、`m=调整` 和 `Esc`。命令面板、选择器、工作区搜索和帮助浮层也是如此，在它们之中 `Ctrl+N` 不再让列表下移。`Alt+G`（`palette.arrange`）是另一种方式，在所有对话框和弹窗上都有效，无需前缀即可调整最前面的那个。
- **一项设置**（`ui.dialog_geometry`，设置 > 外观 > 布局）适用于所有对话框：每个对话框各自记住自己的位置和大小，可以只在本次会话、保存到磁盘留到下次启动，或从不记住。

| 对话框 | 移动 | 调整大小 |
|---|---|---|
| 撤销历史 / Reflog / 丢失的工作、活动日志、任务面板、文件夹选择器 | 是 | 是 |
| 命令面板、标签页 / 主题 / 语言选择器、工作区搜索 | 是 | 是（列表随高度变长，行随宽度变宽） |
| 克隆（仓库列表）、pull request 和新建议题（描述）、“发送的内容”（窗格）、Mermaid（预览）、审查选项（字段，仅宽度） | 是 | 是 |
| 设置中的长文本编辑器（模板、钩子、AI 提示词），工作区表单的 AI 框 | 是 | 是（文本区域） |
| 历史改写：两个 AI 辅助对话框 | 是 | 是（描述、发送窗格） |
| 关于、更新面板、安全检查、预测的冲突、“超出 AI 限额”、删除标签、敏感文件 | 是 | 否（大小随文字而定） |
| 初始化、Worktree、稀疏检出、Flow 对话框、议题流程对话框、commit 消息（reword）表单、工作区表单、标签 / 里程碑选择器 | 是 | 否 |
| 确认提示（每一个“确定吗？”） | 是 | 否 |
| 审查和看板对话框：其中的小对话框（评论、完成、选择、列） | 是 | 否 |
| 快捷键页面的弹窗（重置确认、按键捕获），AI 回答弹窗 | 是 | 否 |
| 设置：仓库认证结果和确认 | 是 | 否 |
| 历史改写：清除、身份和提问对话框 | 是 | 否 |
| 提交编写器的移动文件弹窗，合并提示 | 是 | 否 |

不可移动的有：整页屏幕（设置、帮助、审查页和看板页，它们本就占满窗口）、上下文菜单和下拉列表（它们依附于打开它们的元素）、工具提示，以及页面内部的小弹窗（远程仓库表单、拆分 commit 编辑器）。

指针在标题栏上显示移动形状，在边框和角上显示调整大小的形状（支持 `OSC 22` 的终端）。

## 鼠标指针形状

有些终端允许 GitPoulpi 改变鼠标指针：在分隔条上、在 Log、Radar 和 commit 列的列边界上（拖动时也是）显示调整大小的指针，在可点击项上显示手形。这在 kitty、foot、Ghostty、mintty 以及带有上游 PR #8092 的 WezTerm 构建中有效（使用 `OSC 22` 序列）。它只在形状改变时才发送；在 tmux 内只以透传包装的形式发送（`allow-passthrough on`；kitty 和 foot 会显示，Ghostty 不会），在 screen、zellij 或 herdr 内从不发送。GitPoulpi 退出时会恢复默认指针。在其他终端（Rio、Alacritty、Tabby、iTerm2、Terminal.app、Windows Terminal、xterm）中，指针不会改变；参见[选择终端](terminals.md#鼠标指针形状osc-22)。无论在哪个终端中，指针下方的分隔条或按钮都会亮起。

同类组件在应用各处给出相同的指针。

- **按钮是真正的按钮**，在设置中（集成：编辑、断开连接、移除、浏览、删除，指令编辑器的片段按钮……）和对话框中一样：带内边距的标签配填充背景，指针经过时变亮，禁用时变暗，绝不是 `[ ]` 括起来的文字。仅剩的方括号是复选框标记 `[x]` / `[ ]`，它们是复选框，与其他控件一样显示手形。
- **手形指针**用于控件：按钮、复选框和开关，组合框（在设置、议题和拉取请求窗格、Radar、对话框中），标签页及其叉号，`+` 按钮，链接和引用（`#12`、`!45`），带展开箭头的分组和文件夹标题，ref 药丸，滚动条，以及状态栏的“活动”、任务和版本按钮。行内的复选框或按钮保持手形。
- **箭头**用于行。指针在行上时，整行会亮起（所有列表的亮起方式相同），行本身不是控件：引用、Worktree、Stash 和子模块窗格的行，Log 和 commit 列（只有 ref 药丸显示手形），diff 的各行，更改的文件，拉取请求、议题和 Radar 的条目，以及对话框和面板中列表的行（克隆、文件夹选择器、工作空间、看板的卡片、任务面板、负责人、标签和里程碑选择器、变基步骤、评审的文件和 commit、菜单和组合框的选项）。
- **文本光标（I 形）**用于输入框，覆盖整个框：搜索框（全局搜索、设置、命令面板、主页），筛选框（引用、文件、Radar、活动日志、议题窗格搜索），设置中的文本、数字和多行文本行（编辑时也是），对话框的字段，评审评论框，commit 编写器，文件编辑器的文本，以及合并编辑器的可编辑结果（其只读窗格保持箭头）。在 commit 详情中，消息和描述是可编辑的，所以其上显示 I 形光标，整块会轻轻亮起。
- **在 commit 详情中**，信息行是控件：点击 `commit: <id>` 复制短 id，双击作者或日期行可修订它（手形和淡淡的标记提示这一点）。统计行只提供信息，保持箭头。

调整大小的指针保持在分隔条和列边界上，张开的手只在你携带 ref 时显示。

## 复制到剪贴板

复制操作会把文本放到 GitPoulpi 所在机器的系统剪贴板上，并在已知终端会响应时同时把它发送给终端（OSC 52）。通过 SSH 或没有显示器时只发送 OSC 52：如果你的终端不支持（iTerm2 在打开剪贴板权限之前、Terminal.app、GNU screen），则不会复制任何内容，状态栏会说明文本只是发送给了终端。参见[选择终端](terminals.md#剪贴板复制操作)。
